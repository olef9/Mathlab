# 🎓 Période 5 — Partager et transmettre

> *Après avoir cherché, créé et réalisé des projets, les élèves deviennent les ambassadeurs du Math'Lab.*

---

# Objectifs de la période

La dernière période permet aux élèves de :

- présenter leurs réalisations ;
- expliquer leurs démarches ;
- valoriser leurs progrès ;
- transmettre leur expérience.

L'objectif est de prendre conscience du chemin parcouru pendant l'année.

---

# La grande évolution de l'élève

L'élève passe progressivement de :

> "Je réalise pour apprendre"

à :

> "Je partage pour faire apprendre."

---

# Les compétences Math'Lab développées

## 🎤 Communiquer

Les élèves apprennent à :

- présenter un travail ;
- expliquer une démarche ;
- répondre aux questions ;
- adapter leur discours à un public.

---

## 🌟 Valoriser

Les élèves prennent conscience :

- de leurs progrès ;
- des compétences développées ;
- des difficultés surmontées.

---

## 🤝 Transmettre

Les élèves deviennent capables de partager :

- une méthode ;
- une création ;
- une stratégie ;
- une expérience.

---

## 🔄 Prendre du recul

Les élèves réalisent un bilan :

- ce qu'ils ont appris ;
- ce qu'ils ont aimé ;
- ce qu'ils ont amélioré ;
- ce qu'ils souhaitent continuer à développer.

---

# Les grands moments de la période

---

# 🏛️ L'exposition Math'Lab

Les réalisations peuvent être présentées :

- aux autres classes ;
- aux familles ;
- lors des portes ouvertes ;
- dans le laboratoire.

Exemples :

- jeux mathématiques ;
- créations géométriques ;
- programmes Scratch ;
- objets 3D ;
- parcours MathCity.

---

# 🎤 Les présentations de projets

Chaque équipe présente son travail.

Elle explique :

- l'idée de départ ;
- les choix réalisés ;
- les difficultés rencontrées ;
- les améliorations apportées.

---

# 🏅 La reconnaissance des parcours

La fin d'année permet de valoriser les élèves avec :

- badges obtenus ;
- niveaux atteints ;
- réussites particulières ;
- projets réalisés.

Chaque parcours est différent.

---

# 📖 La mémoire du Math'Lab

Les traces de l'année sont conservées :

- carnets d'équipe ;
- photos ;
- productions ;
- affiches ;
- bilans.

Elles constituent la mémoire du laboratoire.

---

# 🚀 Le dernier défi collectif

Une dernière mission peut réunir toute la classe.

Exemples :

- grande énigme finale ;
- construction collective ;
- défi coopératif ;
- création commune.

L'objectif est de terminer l'année par une réussite partagée.

---

# Préparer l'année suivante

Les élèves peuvent transmettre leur expérience :

- conseils aux futurs élèves ;
- présentation du fonctionnement ;
- création d'un guide du Math'Lab.

Ils deviennent les premiers ambassadeurs du laboratoire.

---

# Les réussites valorisées

Les derniers badges peuvent reconnaître :

- Ambassadeur Math'Lab ;
- Transmetteur ;
- Grand Créateur ;
- Légende du Math'Lab.

---

# Bilan de période

À la fin de l'année, l'élève doit pouvoir dire :

> "Je sais chercher, créer, travailler avec les autres et partager mes découvertes."

---

# Le parcours complet

Au fil de l'année, l'élève est passé par cinq étapes :

🌱 **Entrer dans le Math'Lab**  
Découvrir un nouveau fonctionnement.

🔎 **Devenir chercheur**  
Apprendre à explorer et raisonner.

🛠️ **Manipuler et créer**  
Utiliser des outils pour réaliser.

🚀 **Développer des projets**  
Construire une réalisation collective.

🎓 **Partager et transmettre**  
Faire vivre les mathématiques autour de soi.

---

# À retenir

Le Math'Lab ne se termine pas avec une dernière séance.

Il laisse :

- des compétences ;
- des créations ;
- des souvenirs ;
- une nouvelle manière de voir les mathématiques.
