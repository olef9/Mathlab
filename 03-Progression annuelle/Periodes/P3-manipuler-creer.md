# 🛠️ Période 3 — Manipuler et créer

> *Transformer une idée en réalisation grâce aux outils du Math'Lab.*

---

# Objectifs de la période

Après avoir découvert le fonctionnement du laboratoire et développé des stratégies de recherche, les élèves apprennent à créer.

Ils développent leur capacité à :

- concevoir une réalisation ;
- utiliser différents outils ;
- expérimenter ;
- améliorer une production.

---

# La grande évolution de l'élève

L'élève passe progressivement de :

> "Je cherche une solution"

à :

> "J'imagine, je construis et j'améliore une réalisation."

---

# Les compétences Math'Lab développées

## 💡 Imaginer

Les élèves apprennent à :

- proposer des idées ;
- faire des choix ;
- concevoir un projet ;
- anticiper une réalisation.

---

## 🛠️ Construire

Les élèves développent leur capacité à :

- manipuler ;
- fabriquer ;
- programmer ;
- modéliser.

---

## 🔄 Améliorer

Les élèves comprennent qu'une première réalisation peut évoluer.

Ils apprennent à :

- tester ;
- analyser ;
- corriger ;
- améliorer.

---

## 🤝 Collaborer

Les équipes apprennent à gérer une réalisation plus complexe :

- répartir les tâches ;
- organiser le travail ;
- prendre des décisions collectives.

---

# Les outils du Math'Lab prennent une nouvelle dimension

Les outils déjà découverts deviennent des moyens de création.

---

# 📐 Géométrie et constructions

Les élèves réalisent des productions plus ambitieuses :

Exemples :

- constructions géométriques complexes ;
- pavages ;
- rosaces ;
- figures avec contraintes ;
- maquettes.

La géométrie devient un outil de création.

---

# 🌀 Origamaths

Les pliages mathématiques permettent de travailler :

- précision ;
- propriétés géométriques ;
- symétrie ;
- construction.

Les productions peuvent devenir de véritables objets mathématiques.

---

# 💻 Scratch

Les élèves passent progressivement :

de :

> modifier un programme existant

à :

> créer leur propre programme.

Exemples :

- jeu mathématique ;
- animation ;
- quiz interactif ;
- défi logique.

---

# 🏙️ MathCity

Les élèves commencent à imaginer des situations mathématiques dans leur environnement.

Ils peuvent :

- repérer un lieu intéressant ;
- inventer une question ;
- réfléchir à une énigme.

---

# 🖨️ Découverte de la modélisation 3D

Cette période peut être l'occasion d'une première approche de Tinkercad.

Objectifs :

- comprendre la logique de la modélisation 3D ;
- manipuler des formes simples ;
- créer un premier objet.

Exemples :

- solide géométrique ;
- pièce de puzzle ;
- objet mathématique simple.

La maîtrise complète viendra progressivement.

---

# Les défis de la période

Les défis deviennent plus créatifs.

Exemples :

## 🎲 Défi création

Créer un jeu mathématique répondant à certaines contraintes.

---

## 📐 Défi géométrique

Créer une figure ou un objet respectant plusieurs propriétés.

---

## 💻 Défi programmation

Créer une activité numérique permettant de faire travailler une notion mathématique.

---

# Les projets courts

Les élèves peuvent réaliser des productions sur plusieurs séances.

Exemples :

- jeu mathématique ;
- objet géométrique ;
- programme Scratch ;
- création Origamaths ;
- objet 3D simple.

---

# Les mathématiques travaillées

Les créations permettent de mobiliser :

- géométrie ;
- grandeurs et mesures ;
- calcul ;
- proportionnalité ;
- algorithmique ;
- résolution de problèmes.

---

# Les réussites valorisées

Les élèves peuvent obtenir des badges liés à la création :

- Inventeur ;
- Créateur ;
- Programmeur ;
- Architecte.

---

# Bilan de période

À la fin de la période, l'élève doit pouvoir dire :

> "Je sais utiliser des outils mathématiques pour créer quelque chose."

Il sait :

- imaginer une solution ;
- construire une réalisation ;
- expliquer ses choix ;
- améliorer son travail.
