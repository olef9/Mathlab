# 🌱 Période 1 — Entrer dans le Math'Lab

> *Découvrir un nouveau laboratoire de mathématiques, apprendre à coopérer et commencer à explorer.*

---

# Objectifs de la période

La première période installe les bases du Math'Lab.

Les élèves découvrent progressivement :

- le fonctionnement du laboratoire ;
- les équipes ;
- les outils ;
- les habitudes de recherche ;
- la place de l'erreur dans les apprentissages.

L'objectif principal est de permettre à chacun de trouver sa place dans ce nouvel environnement.

---

# La grande évolution de l'élève

Au début de l'année, l'élève passe progressivement de :

> "Je découvre une nouvelle façon de faire des mathématiques"

à :

> "Je participe à un laboratoire où je peux chercher, manipuler et coopérer."

---

# Les compétences Math'Lab développées

## 👥 Coopérer

Les élèves apprennent à :

- travailler en équipe ;
- écouter les propositions des autres ;
- respecter les rôles ;
- construire une réponse collective.

---

## 🔎 Chercher

Les élèves découvrent que faire des mathématiques, c'est aussi :

- essayer ;
- se tromper ;
- recommencer ;
- comparer des stratégies.

---

## 🛠️ Manipuler

Les élèves prennent en main progressivement :

- le matériel géométrique ;
- les outils de construction ;
- les supports de manipulation ;
- les outils numériques.

---

## 📣 Communiquer

Les élèves commencent à :

- expliquer leurs idées ;
- présenter une démarche ;
- écouter les solutions des autres équipes.

---

# La vie du Math'Lab pendant cette période

## 👥 Les équipes

Installation progressive :

- constitution des équipes ;
- choix d'un nom ;
- création d'une identité ;
- découverte des rôles.

Les élèves apprennent à fonctionner ensemble.

---

## 🧩 Les défis

Les défis apparaissent dès les premières semaines.

Ils permettent de découvrir l'esprit Math'Lab.

Exemples :

- énigmes courtes ;
- défis de logique ;
- constructions avec contraintes ;
- défis de coopération.

L'objectif principal est d'apprendre à chercher ensemble.

---

## 🏅 Les premiers badges

Les premières réussites peuvent être valorisées.

Exemples :

- Coéquipier ;
- Organisateur ;
- Explorateur ;
- Persévérant.

---

# Les outils découverts progressivement

Dès cette période, les élèves peuvent expérimenter :

## 📐 Géométrie

- constructions simples ;
- reproduction de figures ;
- manipulations.

---

## 🌀 Créations

- pavages ;
- pliages ;
- premières créations géométriques.

---

## 💻 Numérique

Découverte possible :

- d'un programme Scratch existant ;
- d'une activité interactive ;
- d'une première création simple.

---

# Les mathématiques travaillées

Les notions du programme de 6e sont abordées à travers les activités du laboratoire.

Exemples :

- calcul et stratégies de calcul ;
- nombres entiers ;
- premiers problèmes ;
- repérage ;
- constructions géométriques.

Les élèves découvrent que les mathématiques peuvent être explorées de différentes façons.

---

# Les premières traces

Les élèves commencent à construire la mémoire du Math'Lab :

- carnet d'équipe ;
- productions ;
- affichages ;
- premières réussites.

---

# Bilan de période

À la fin de la période, l'élève doit pouvoir dire :

> "Je sais comment fonctionne le Math'Lab et je sais travailler avec mon équipe."

Il connaît :

- les règles ;
- les rôles ;
- les outils ;
- les habitudes de recherche.
