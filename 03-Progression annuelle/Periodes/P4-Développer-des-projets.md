# 🚀 Période 4 — Développer des projets

> *Passer d'une création personnelle à une réalisation collective organisée.*

---

# Objectifs de la période

Après avoir appris à chercher, manipuler et créer, les élèves développent leur capacité à mener un projet.

Ils apprennent à :

- définir un objectif ;
- organiser un travail collectif ;
- répartir les responsabilités ;
- réaliser une production complète ;
- présenter leur démarche.

---

# La grande évolution de l'élève

L'élève passe progressivement de :

> "Je crée quelque chose"

à :

> "Je construis un projet avec une équipe."

---

# Les compétences Math'Lab développées

## 🎯 Concevoir un projet

Les élèves apprennent à :

- imaginer une réalisation ;
- définir un objectif ;
- identifier les contraintes ;
- prévoir les étapes.

---

## 📋 Organiser

Les équipes développent leur autonomie.

Elles apprennent à :

- répartir les rôles ;
- planifier les tâches ;
- gérer le matériel ;
- suivre l'avancement.

---

## 🛠️ Réaliser

Les élèves mobilisent les outils du Math'Lab :

- manipulation ;
- géométrie ;
- programmation ;
- création numérique ;
- modélisation.

---

## 🔎 Améliorer

Un projet évolue grâce aux essais.

Les élèves apprennent à :

- tester ;
- recueillir des avis ;
- corriger ;
- perfectionner.

---

# Les grands projets possibles

Cette période peut accueillir des réalisations plus ambitieuses.

---

# 🏙️ Projet MathCity

Les élèves peuvent créer un parcours mathématique.

Ils travaillent sur :

- le choix d'un lieu ;
- la création d'énigmes ;
- les mesures ;
- les consignes ;
- les solutions.

Objectif :

Faire vivre les mathématiques dans l'environnement réel.

---

# 💻 Projet Scratch

Les équipes peuvent concevoir :

- un jeu mathématique ;
- une animation ;
- une activité interactive ;
- un défi numérique.

Les élèves doivent penser :

- règles du jeu ;
- programmation ;
- ergonomie ;
- explications.

---

# 🖨️ Projet Tinkercad

La modélisation 3D peut permettre de créer :

- un objet mathématique ;
- un support pédagogique ;
- un puzzle ;
- une pièce de construction.

Les élèves découvrent une démarche proche de la conception industrielle :

idée → modèle → test → amélioration.

---

# 🎲 Projet jeu mathématique

Les équipes peuvent concevoir un jeu complet :

- règles ;
- plateau ;
- cartes ;
- matériel ;
- stratégie.

Le jeu doit permettre de faire vivre une notion mathématique.

---

# 🌀 Projet géométrique

Exemples :

- exposition de pavages ;
- créations Origamaths ;
- constructions collectives ;
- œuvres mathématiques.

---

# La gestion de projet

Chaque équipe apprend à utiliser une démarche simple :

## 1. L'idée

Que voulons-nous créer ?

---

## 2. Le cahier des charges

Quelles sont les contraintes ?

Exemples :

- dimensions ;
- règles ;
- public visé ;
- matériel disponible.

---

## 3. La réalisation

Construction progressive du projet.

---

## 4. Les tests

Les équipes vérifient :

- ce qui fonctionne ;
- ce qui doit être amélioré.

---

## 5. La présentation

Le projet est expliqué à un public.

---

# Les défis continuent

Même pendant les projets, les défis restent présents.

Ils peuvent servir à :

- débloquer une difficulté ;
- tester une idée ;
- gagner des XP ;
- développer une compétence.

---

# Les mathématiques travaillées

Les projets mobilisent de nombreuses compétences :

- calcul ;
- géométrie ;
- grandeurs et mesures ;
- proportionnalité ;
- algorithmique ;
- communication mathématique.

---

# Les réussites valorisées

Les badges peuvent récompenser :

- Chef de projet ;
- Concepteur ;
- Collaborateur ;
- Expert technique ;
- Communicateur.

---

# Bilan de période

À la fin de la période, l'élève doit pouvoir dire :

> "Je sais mener un projet mathématique avec une équipe."

Il sait :

- organiser un travail ;
- utiliser des outils ;
- résoudre des problèmes ;
- présenter une réalisation.
