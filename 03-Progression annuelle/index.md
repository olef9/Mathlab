# 📅 Progression annuelle du Math’Lab

> Une année pour apprendre les mathématiques autrement : chercher, construire, créer et partager.

---

## Objectif de cette progression

La progression annuelle présente l’organisation du Math’Lab sur l’ensemble de l’année scolaire.

Elle permet de suivre :

- les apprentissages mathématiques ;
- l’évolution des élèves ;
- les défis proposés ;
- les projets réalisés ;
- les temps forts du laboratoire.

---

## Une progression différente

Le Math’Lab ne suit pas uniquement une succession de chapitres.

Chaque période associe les apprentissages mathématiques à la vie du laboratoire.

### 📚 Les apprentissages mathématiques

Les notions du programme de 6e sont travaillées à travers :

- des recherches ;
- des manipulations ;
- des problèmes ;
- des défis ;
- des productions.

### 🧩 La vie du laboratoire

Tout au long de l’année, les élèves retrouvent :

- les équipes ;
- les défis ;
- les XP ;
- les badges ;
- les projets.

---

## Organisation de l’année

L’année est organisée en cinq grandes périodes.

### 🌱 Période 1 — Entrer dans le Math’Lab

Découvrir les règles et les habitudes de travail du laboratoire.

Objectifs :

- créer les équipes ;
- apprendre à coopérer ;
- découvrir les outils ;
- installer les habitudes de recherche.

### 🔎 Période 2 — Devenir chercheur

Développer les stratégies mathématiques.

Objectifs :

- chercher ;
- argumenter ;
- tester ;
- expliquer.

### 🛠️ Période 3 — Manipuler et créer

Passer de la recherche à la réalisation.

Objectifs :

- construire ;
- programmer ;
- expérimenter ;
- créer.

### 🚀 Période 4 — Développer des projets

Donner une place plus importante aux réalisations longues.

Objectifs :

- organiser un projet ;
- collaborer ;
- améliorer une production.

### 🎓 Période 5 — Partager et transmettre

Valoriser le parcours accompli.

Objectifs :

- présenter ;
- expliquer ;
- transmettre ;
- célébrer les réussites.

---

## Les fils rouges de l’année

### 👥 Les équipes

Les élèves apprennent progressivement à travailler ensemble.

### 🧩 Les défis

Les défis rythment les apprentissages et développent la recherche.

### ⭐ La progression personnelle

Les XP, les badges et les niveaux rendent visibles les évolutions.

### 🏗️ Les projets

Les réalisations donnent du sens aux apprentissages.
