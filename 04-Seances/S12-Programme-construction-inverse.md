# S12 – Le programme de construction inversé

## Idée générale

Chaque équipe reçoit une **figure secrète** et le support de départ correspondant.

Elle doit rédiger un programme de construction permettant à une autre équipe de reproduire la figure **sans jamais la voir**.

La seconde équipe exécute le programme à la lettre. Elle ne cherche pas à deviner l'intention des auteurs.

Après le test, les deux équipes comparent la construction obtenue à la figure secrète, repèrent les ambiguïtés et rédigent une version améliorée.

La production centrale n'est donc pas seulement la figure : c'est le passage de la **version 1** à la **version 2** du programme.

# Mission du jour

> Votre équipe connaît une figure que l'équipe voisine ne peut pas voir.  
> Rédigez un programme suffisamment précis pour qu'elle puisse reconstruire cette figure à partir du support fourni.  
> Vous n'avez pas le droit de montrer, de mimer ou de décrire oralement la figure pendant le premier test.

## Contrat de communication

Pendant la première exécution :

- les auteurs ne montrent pas la carte secrète ;
- les auteurs ne parlent pas ;
- les auteurs ne font aucun geste ;
- les testeurs suivent les instructions dans l'ordre ;
- les testeurs signalent les passages ambigus, mais ne demandent pas immédiatement une explication ;
- les erreurs sont conservées : elles servent à améliorer le programme.

---

# Vocabulaire utile

Les élèves peuvent utiliser :

- point ;
- segment ;
- droite ;
- diagonale ;
- côté ;
- milieu ;
- centre ;
- cercle ;
- rayon ;
- intersection ;
- relier ;
- tracer ;
- placer ;
- passant par ;
- de centre… et passant par… ;
- à l'intérieur ou à l'extérieur de la figure.

Formulations à éviter :

```text
Fais un trait ici.
Trace comme sur le dessin.
Relie les points qui vont ensemble.
Fais la même chose de l'autre côté.
Dessine un petit cercle.
```

# Organisation

Chaque équipe de trois ou quatre reçoit une carte secrète différente :

| Carte | Support initial |
|---|---|
| A – La cible carrée | Carré `ABCD` |
| B – Le moulin | Carré `ABCD` |
| C – L'œil triangulaire | Triangle `ABC` |
| D – La roue | Cercle de centre `O` avec deux diamètres |

Les équipes sont associées par deux :

```text
équipe 1 ↔ équipe 2
équipe 3 ↔ équipe 4
```

Une équipe écrit d'abord pour l'autre, puis les rôles peuvent être inversés lors d'un second défi ou d'une reprise.

## Rôles possibles

### Équipe auteure

- observateur de la figure ;
- responsable du vocabulaire ;
- rédacteur ;
- vérificateur de l'ordre.

### Équipe testeuse

- lecteur ;
- constructeur ;
- contrôleur des étapes ;
- rapporteur des ambiguïtés.

---

# Préparation de l'enseignant

## Matériel

Pour chaque équipe auteure :

- une carte secrète ;
- le support initial correspondant ;
- la fiche auteurs ;
- une règle ;
- un compas ;
- un crayon à papier.

Pour chaque équipe testeuse :

- un support initial vierge ;
- la fiche testeurs ;
- une règle ;
- un compas ;
- le programme écrit par l'autre équipe.

## Avant la séance

- découper les cartes secrètes ;
- ne pas distribuer les cartes avant le lancement ;
- imprimer plusieurs exemplaires des supports récepteurs ;
- associer les équipes par deux ;
- vérifier que les groupes placés côte à côte ne peuvent pas voir les cartes des autres ;
- conserver les défis avancés pour les équipes rapides.

# Déroulement détaillé

## 1. Rituel Rallye – 6 minutes

Utiliser :

**RALLYE-01 – Tétonor express**

Les élèves doivent associer les nombres par paires en utilisant une somme et un produit.

Correction très courte : faire expliquer comment une paire fournit deux cibles.

---

## 2. Lancement : une consigne peut-elle être exécutée ? – 5 minutes

Écrire :

```text
Trace un cercle au milieu du carré.
```

Demander :

- Où est exactement le milieu du carré ?
- Quel est le rayon ?
- Le cercle doit-il toucher les côtés ?
- Deux élèves obtiendraient-ils forcément la même figure ?

Transformer collectivement la phrase :

```text
Trace les diagonales du carré ABCD.
Nomme O leur point d'intersection.
Trace le cercle de centre O passant par le milieu du segment [AB].
```

Faire émerger :

> Une instruction précise permet à deux personnes différentes d'obtenir la même construction.

---

## 3. Observation de la figure secrète – 5 minutes

Distribuer une carte par équipe.

Consigne :

> Pendant deux minutes, observez sans écrire.  
> Décomposez la figure en étapes simples.  
> Cherchez ce qui doit être construit avant le reste.

Questions à traiter :

- Quels points sont déjà donnés ?
- Quels nouveaux points doivent être nommés ?
- Quelles constructions dépendent d'autres constructions ?
- Quels instruments sont nécessaires ?
- Quel ordre paraît le plus logique ?

---

## 4. Rédaction du programme – Version 1 – 11 minutes

Les équipes complètent la fiche auteurs.

Contraintes :

- numéroter toutes les étapes ;
- nommer chaque nouveau point ;
- indiquer le centre et un point du cercle ;
- éviter les mesures à l'œil ;
- ne pas écrire le nom ou l'apparence finale de la figure ;
- relire le programme comme si l'on ne connaissait pas la carte.

### Test interne obligatoire

Un membre cache la carte et lit le programme.

Les autres pointent mentalement chaque construction sur le support initial.

---

## 5. Échange et exécution silencieuse – 10 minutes

Les cartes secrètes restent chez les auteurs.

Chaque équipe testeuse reçoit :

- le programme ;
- le support initial correspondant ;
- la fiche testeurs.

Pendant les six premières minutes, les auteurs restent silencieux.

Les testeurs :

1. exécutent chaque étape ;
2. entourent les mots inconnus ;
3. marquent `?` devant une instruction ambiguë ;
4. n'inventent pas une étape manquante ;
5. conservent toutes les traces.

---

## 6. Comparaison et diagnostic – 6 minutes

La carte secrète est enfin montrée.

Les deux équipes comparent :

- la figure attendue ;
- la construction obtenue ;
- le programme écrit.

Elles classent les problèmes :

```text
☐ étape oubliée
☐ mauvais ordre
☐ point non nommé
☐ instrument ou rayon non précisé
☐ vocabulaire ambigu
☐ consigne correcte mais mal exécutée
```

Le but n'est pas de désigner un responsable, mais d'identifier l'origine de l'écart.

---

## 7. Réécriture – Version 2 – 7 minutes

L'équipe auteure améliore son programme.

Elle doit modifier au moins une formulation, même si la figure a été reproduite correctement.

Exemples d'améliorations :

- remplacer « trace les diagonales » par leur nom ;
- préciser l'ordre des points ;
- nommer une intersection ;
- préciser « cercle de centre O passant par E » ;
- séparer une consigne trop longue en deux étapes ;
- supprimer une instruction inutile.

Les versions 1 et 2 sont conservées.

---

## 8. Bilan – 5 minutes

Chaque binôme d'équipes choisit une amélioration importante.

Questions :

- Quelle instruction a provoqué le plus grand écart ?
- Une instruction mathématiquement correcte peut-elle rester difficile à comprendre ?
- Pourquoi faut-il tester un programme sur une personne qui ne connaît pas la figure ?
- Quelle différence existe entre une erreur de rédaction et une erreur d'exécution ?

Synthèse :

> Un bon programme de construction doit être précis, ordonné, complet et testable.

# Différenciation

## Aide légère

Donner la banque de vocabulaire.

Demander :

> Le point utilisé dans cette phrase a-t-il déjà été nommé ?

## Aide intermédiaire

Fournir le début du programme :

```text
1. Trace les diagonales…
2. Nomme O…
```

ou un tableau :

| Étape | Action | Point créé |
|---:|---|---|
| 1 | | |
| 2 | | |

## Aide renforcée

- donner la liste non ordonnée des actions ;
- faire remettre les étapes dans l'ordre ;
- fournir une carte où un seul cercle est nécessaire ;
- autoriser une première construction sur un échiquier de points avant le programme écrit.

## Élèves rapides

Utiliser :

**Construction-inversee-Defis-avances.svg**

Deux figures plus complexes sont proposées :

- E – L'étoile des milieux ;
- F – Le double blason.

Les auteurs doivent en plus :

- limiter le programme à dix étapes ;
- éviter toute phrase contenant « pareil » ou « même chose » ;
- faire tester la figure par une équipe différente ;
- calculer le nombre de corrections entre les versions 1 et 2.

---

# Observation de l'enseignant

Observer notamment :

- la décomposition de la figure ;
- l'ordre choisi ;
- la nomination des points ;
- la précision des cercles ;
- la distinction entre segment et droite ;
- la réaction à une mauvaise interprétation ;
- la qualité du retour des testeurs ;
- la réalité de la réécriture.

Une équipe qui réussit la figure du premier coup doit tout de même analyser et améliorer son programme : l'objectif est la communication, pas uniquement la construction.
