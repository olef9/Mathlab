# S17 – Red fish : l’animal compassé

## Idée générale

Les élèves reproduisent **Red fish**, activité de la collection *Papiers Crayons* de l’IREM Paris-Nord, dans la partie :

```text
Avec le compas seul, des cercles et des arcs de cercles
```

La figure est construite principalement avec des arcs. Les élèves disposent :

- du modèle officiel ;
- de la feuille de départ officielle ;
- d’un compas ;
- d’un crayon à papier ;
- d’aucune règle graduée.

La mission ne consiste pas à mesurer ou à recopier à l’œil. Il faut retrouver :

- les points qui servent de centres ;
- les points qui règlent l’ouverture ;
- les arcs appartenant au même cercle ;
- l’ordre dans lequel les intersections deviennent disponibles.

# Mission du jour

> Reproduisez l’animal en utilisant uniquement le compas.  
> Les points de départ ne sont pas tous des sommets : certains servent de centres, d’autres règlent l’ouverture du compas ou apparaissent comme intersections.

## Interdictions

- mesurer une longueur ;
- utiliser la règle pour tracer ;
- dessiner un arc à main levée ;
- déplacer une pointe déjà réglée « à peu près » ;
- repasser un cercle entier sans savoir quel arc est utile ;
- gommer les centres avant la vérification.

## Autorisations

- tracer très légèrement un cercle complet pour faire apparaître ses intersections ;
- utiliser une couleur sur le modèle pour regrouper les arcs supposés appartenir au même cercle ;
- faire un essai sur une feuille de brouillon ;
- comparer les stratégies au sein de l’équipe ;
- conserver les traits de recherche jusqu’à la validation.

# Préparation de l’enseignant

## Matériel par élève

- modèle officiel Red fish ;
- support officiel de construction ;
- compas en bon état ;
- crayon à papier bien taillé ;
- gomme ;
- fiche mission ;
- éventuellement deux crayons de couleur pour annoter le modèle.

## Matériel collectif

- agrandissement du modèle ;
- support `Lunules-Echauffement.svg` ;
- quelques compas de secours ;
- feuilles de brouillon ;
- défi original pour les élèves rapides.

## Avant la séance

- télécharger les fichiers depuis la page officielle de Papiers Crayons ;
- choisir la version d’impression contenant le modèle et le support de départ ;
- vérifier que les points sont nets après photocopie ;
- tester la construction ou au minimum repérer les principales familles d’arcs ;
- préparer une production partiellement réussie comportant un raccord incorrect ;
- ne pas distribuer de programme complet de construction.

# Déroulement détaillé

## 1. Rituel – 5 minutes

Utiliser :

**CM-05 – Doubles, moitiés et quarts**

La mise en commun reste très courte.

---

## 2. Échauffement : deux cercles, une lunule – 6 minutes

Distribuer ou projeter :

**Lunules-Echauffement.svg**

Étapes :

1. placer la pointe sèche en `A` ;
2. ouvrir le compas jusqu’à `B` ;
3. tracer le cercle de centre `A` passant par `B` ;
4. conserver la même ouverture ;
5. tracer le cercle de centre `B` passant par `A` ;
6. observer les deux intersections.

Questions :

- Pourquoi les deux cercles ont-ils le même rayon ?
- Quels points appartiennent aux deux cercles ?
- Quelles formes apparaissent entre les arcs ?
- Peut-on tracer seulement la « feuille » sans avoir compris les deux cercles ?

Faire émerger le mot :

```text
lunule
```

et le réflexe :

```text
centre → ouverture → arc utile
```

---

## 3. Observation silencieuse de Red fish – 5 minutes

Distribuer le modèle officiel sans le support de construction pendant deux minutes.

Consigne :

> Ne tracez rien. Cherchez des familles d’arcs.

Sur la fiche mission, les élèves notent :

- nombre approximatif de grandes ouvertures ;
- arcs qui semblent partager un centre ;
- parties symétriques ou répétées ;
- cercle ou arc à construire probablement en premier ;
- zone qui paraît la plus difficile.

## Mise en commun rapide

Ne pas valider toutes les hypothèses.

Retenir seulement :

- plusieurs arcs ont la même ouverture ;
- une intersection peut devenir un nouveau centre ;
- le contour de l’animal n’est pas nécessairement construit en premier.

---

## 4. Recherche des premiers arcs – 9 minutes

Distribuer la feuille de départ officielle.

Objectif intermédiaire :

> Construire correctement une première famille d’arcs et faire apparaître au moins une nouvelle intersection utile.

Méthode proposée :

1. choisir un point supposé être un centre ;
2. choisir un second point pour régler le rayon ;
3. vérifier sur le modèle quels arcs pourraient appartenir à ce cercle ;
4. tracer légèrement ;
5. comparer les intersections obtenues au modèle ;
6. conserver ou abandonner l’hypothèse.

## Relances possibles

- Quel point reste immobile lorsque tu traces cet arc ?
- L’ouverture de ton compas est-elle déjà présente ailleurs ?
- Cet arc rencontre-t-il un point déjà donné ?
- Le cercle complet ferait-il apparaître une intersection utile ?
- As-tu changé le centre ou seulement l’ouverture ?
- Pourquoi penses-tu que ces deux arcs appartiennent au même cercle ?

---

## 5. Construction individuelle – 17 minutes

Chaque élève poursuit la figure.

L’équipe peut échanger des idées, mais chaque élève trace sur son support.

## Règles de précision

- pointe sèche exactement sur le centre ;
- mine du compas fine ;
- cercle léger pendant la recherche ;
- arc définitif repassé après validation ;
- ouverture conservée lorsque plusieurs arcs ont le même rayon ;
- intersections non arrondies à l’œil.

## Étapes de travail conseillées

Sans fournir le programme exact :

1. construire les cercles ou arcs qui utilisent les points déjà donnés ;
2. marquer les nouvelles intersections ;
3. utiliser ces intersections comme centres ou comme points de rayon ;
4. construire les arcs intérieurs ;
5. terminer le contour ;
6. vérifier les raccords ;
7. repasser uniquement les arcs utiles.

## Point d’arrêt possible

Une production peut être validée même si elle n’est pas entièrement coloriée lorsque :

- la structure principale est correcte ;
- les arcs se raccordent ;
- les centres et rayons peuvent être expliqués.

---

## 6. Contrôle croisé – 6 minutes

Par binômes, les élèves vérifient sans corriger directement.

## Grille de contrôle

```text
☐ Les arcs passent par les points attendus.
☐ Les intersections sont nettes.
☐ Deux arcs supposés avoir le même rayon semblent cohérents.
☐ Aucun raccord n’a été dessiné à main levée.
☐ Les traits de recherche permettent encore de retrouver les centres.
☐ Le contour ne présente ni trou ni décalage.
```

## Question obligatoire

Le vérificateur demande :

> Montre-moi le centre et le rayon de l’un de tes arcs.

L’auteur doit pouvoir pointer :

- le centre ;
- le point utilisé pour régler l’ouverture ;
- l’arc obtenu.

---

## 7. Mise en valeur ou défi – 4 à 10 minutes

### Production dans le temps prévu

- repasser les arcs définitifs ;
- gommer seulement les cercles inutiles après validation ;
- colorier en faisant ressortir les lunules ;
- inscrire au dos une phrase expliquant un arc.

### Élèves rapides

Distribuer :

**Poisson-lune-Defi-original.svg**

Ce défi original Math’Lab propose :

- un second poisson composé d’arcs ;
- un modèle ;
- une constellation de points ;
- aucun programme détaillé.

Réussite minimale :

- reconstruire le corps ;
- retrouver la logique de la queue ;
- expliquer deux centres et deux ouvertures.

---

## 8. Bilan – 3 minutes

Questions :

- Pourquoi avons-nous parfois tracé un cercle entier alors que seul un arc apparaît dans la figure ?
- Une même ouverture peut-elle être utilisée avec plusieurs centres ?
- Une même centre peut-il servir avec plusieurs ouvertures ?
- Quelle différence entre « reproduire à l’œil » et « construire » ?
- Quelle intersection a débloqué votre recherche ?

Synthèse :

> Un arc n’est pas seulement une courbe visible. Il appartient à un cercle défini par un centre et un rayon.

# Différenciation

## Aide légère

- colorier deux arcs de même rayon sur une copie du modèle ;
- signaler un premier centre sans donner le rayon ;
- faire fermer les yeux puis verbaliser : « pointe sèche où ? mine où ? ».

## Aide intermédiaire

Donner une carte :

```text
Centre : point ______
Ouverture : distance entre ______ et ______
Arc utile : de ______ à ______
```

## Aide renforcée

- commencer uniquement par l’échauffement et une partie de Red fish ;
- marquer les centres possibles avec une couleur ;
- fournir un cercle déjà tracé ;
- autoriser un calque de contrôle après la recherche ;
- limiter l’objectif à trois familles d’arcs correctement construites.

## Élèves rapides

- réaliser le défi original ;
- trouver le nombre d’ouvertures différentes utilisées ;
- écrire un programme partiel portant sur quatre arcs ;
- créer une petite aile ou nageoire supplémentaire respectant les rayons existants ;
- expliquer pourquoi une ouverture incorrecte produit un décalage croissant ;
- comparer Red fish à la rosace de S07.

# Observation de l’enseignant

Observer notamment :

- la qualité de l’observation avant le tracé ;
- l’identification des centres ;
- la conservation de l’ouverture ;
- la précision des intersections ;
- la capacité à abandonner une hypothèse fausse ;
- l’ordre choisi ;
- le vocabulaire utilisé ;
- la justification d’un arc ;
- l’autonomie avec le compas.

La réussite n’est pas évaluée uniquement à la ressemblance finale. Une figure inachevée mais construite avec des centres et des rayons justifiés peut être plus réussie qu’une figure complète approximative.
