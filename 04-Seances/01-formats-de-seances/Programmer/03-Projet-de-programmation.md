# 🚀 Scratch Projet

> *« Un projet permet de réinvestir ce que l'on sait déjà pour créer quelque chose de nouveau. »*

---

# Principe

Les élèves réalisent un véritable projet avec Scratch.

Ils choisissent une stratégie, organisent leur travail, programment, testent, corrigent puis présentent leur réalisation.

Le projet répond à une mission authentique.

L'objectif n'est pas de découvrir de nouveaux blocs.

Il est de mobiliser les compétences déjà acquises pour répondre à un défi.

---

# Pourquoi utiliser ce format ?

Les projets donnent du sens aux apprentissages.

Ils permettent aux élèves de comprendre que programmer sert à créer, modéliser, représenter ou expliquer des idées mathématiques.

Ils développent :

- l'autonomie ;
- la coopération ;
- la créativité ;
- la persévérance.

---

# Objectifs

Les élèves apprennent à :

- analyser une mission ;
- concevoir un programme ;
- organiser un projet ;
- tester et améliorer une production ;
- présenter leur réalisation.

# Erreurs fréquentes

Les élèves peuvent :

- vouloir programmer immédiatement ;

- oublier de planifier ;

- tester trop rarement ;

- vouloir ajouter trop de fonctionnalités.

Le rappel essentiel :

> Un projet réussi commence toujours par une bonne préparation.

---

# Conseils de mise en œuvre

Limiter les projets à un objectif principal.

Valoriser la qualité plutôt que la quantité.

Prévoir un véritable temps de présentation.
