# 💻 Programmer
## Lire en premier

---

# Pourquoi cette famille ?

Programmer, c'est apprendre à décomposer un problème, organiser ses idées et construire une suite d'actions logiques.

Au Math'Lab, la programmation n'est pas un objectif en soi.

Elle constitue un outil supplémentaire pour développer les compétences mathématiques.

Les élèves découvrent progressivement que programmer demande les mêmes qualités que chercher une solution :

- observer ;
- anticiper ;
- tester ;
- corriger ;
- améliorer.

---

# Une programmation au service des mathématiques

Les activités proposées ne cherchent pas à former des programmeurs.

Elles utilisent la programmation pour développer :

- le raisonnement ;
- la logique ;
- la résolution de problèmes ;
- la précision ;
- la persévérance.

L'objectif est de montrer que les mathématiques permettent de concevoir des programmes, et que les programmes permettent d'explorer les mathématiques.

---

# Une progression pensée pour toute l'année

Les formats de cette famille suivent une progression naturelle.

| Format | Ce qu'il développe principalement |
|--------|-----------------------------------|
| 💻 Algorithmique débranchée | Comprendre la logique d'un algorithme sans ordinateur |
| 🟠 Scratch Découverte | Découvrir les blocs et les structures simples |
| 🚀 Scratch Projet | Concevoir un programme répondant à un objectif |
| 🧱 Tinkercad | Modéliser des objets en trois dimensions |
| 🖨️ Impression 3D | Passer du modèle numérique à un objet réel |

Les activités peuvent être réutilisées plusieurs fois avec des défis de difficulté croissante.

---

# Les principes du Math'Lab

Programmer, c'est accepter qu'un premier essai ne fonctionne pas toujours.

Les élèves apprennent progressivement à :

- prévoir les étapes ;
- tester leur programme ;
- identifier une erreur ;
- corriger ;
- recommencer.

L'erreur est considérée comme une information précieuse.

---

# Le rôle de l'enseignant

Pendant les activités de programmation, l'enseignant accompagne les élèves par le questionnement.

Quelques exemples :

- « Que doit faire ton programme ? »
- « Que se passe-t-il si cette instruction est supprimée ? »
- « Peux-tu prévoir le résultat avant d'exécuter ton programme ? »
- « Pourquoi ton programme ne fonctionne-t-il pas encore ? »
- « Quelle modification proposes-tu ? »

L'objectif est de développer l'autonomie face aux erreurs.

---

# Une progression par essais

Les activités de programmation suivent presque toujours le même cycle :

1. Imaginer.
2. Construire.
3. Tester.
4. Corriger.
5. Améliorer.

Cette démarche est proche de celle utilisée dans la recherche scientifique.

---

# Une place pour la créativité

Programmer ne consiste pas seulement à reproduire un modèle.

Au fil de l'année, les élèves évoluent progressivement :

**Comprendre → Modifier → Créer → Optimiser → Partager**

Ils deviennent progressivement capables de concevoir leurs propres projets.

---

# Valoriser les productions

Les programmes réalisés méritent d'être présentés.

Quelques idées :

- démonstrations devant la classe ;
- galerie de projets Scratch ;
- exposition des modèles 3D ;
- présentation des objets imprimés ;
- portfolio numérique.

Ces réalisations montrent aux élèves que les mathématiques permettent aussi de créer.

---

# Quelques conseils

✔ Faire prédire le résultat avant chaque exécution.

✔ Valoriser les essais et les corrections.

✔ Encourager les élèves à expliquer leur programme.

✔ Réutiliser les programmes dans plusieurs contextes.

✔ Commencer par des défis simples mais ouverts.

✔ Garder les mathématiques au cœur des activités.

---

# En résumé

La programmation développe des compétences qui dépassent largement l'informatique.

Les élèves apprennent à :

- raisonner ;
- organiser leurs idées ;
- tester des hypothèses ;
- corriger leurs erreurs ;
- persévérer.

> **Programmer, c'est apprendre à faire penser une machine… en commençant par organiser sa propre pensée.**
