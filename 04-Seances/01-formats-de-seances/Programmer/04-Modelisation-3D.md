# 🧱 Modélisation 3D

> *« Concevoir un objet, c'est transformer une idée en volume. »*

---

# Principe

Les élèves réalisent un objet numérique en trois dimensions à partir d'une mission.

Ils découvrent progressivement comment construire un modèle précis en utilisant des formes géométriques simples.

L'objectif n'est pas de maîtriser un logiciel.

L'objectif est de mobiliser les mathématiques pour créer un objet.

---

# Pourquoi utiliser ce format ?

La modélisation 3D donne immédiatement du sens aux notions de géométrie.

Les élèves manipulent :

- des solides ;
- des dimensions ;
- des coordonnées ;
- des alignements ;
- des symétries.

Ils comprennent que les mathématiques permettent de concevoir des objets réels.

---

# Objectifs

Les élèves apprennent à :

- représenter un objet en trois dimensions ;
- utiliser les solides usuels ;
- respecter des dimensions ;
- assembler plusieurs formes ;
- améliorer progressivement un modèle.

# Les caractéristiques d'une bonne mission

Une mission :

✔ possède un objectif concret ;

✔ demande une réflexion géométrique ;

✔ laisse une liberté de création ;

✔ produit un objet modélisé.

---

# Exemples de missions

🎯 Concevoir le porte-clés de son équipe.

🎯 Construire un dé équilibré.

🎯 Réaliser un puzzle.

🎯 Créer un solide original.

🎯 Concevoir une pièce d'assemblage.

🎯 Fabriquer un objet utile pour le Math'Lab.

---

# Déroulement type

## 1. Mission

Comprendre le besoin.

Imaginer plusieurs solutions.

---

## 2. Croquis

Dessiner rapidement l'objet.

Identifier :

- les formes ;
- les dimensions ;
- les assemblages.

---

## 3. Modélisation

Construire progressivement le modèle.

Tester.

Corriger.

---

## 4. Vérification

Contrôler :

- les dimensions ;
- les alignements ;
- les proportions.

---

## 5. Présentation

Chaque équipe explique :

- ses choix ;
- les difficultés rencontrées ;
- les améliorations possibles.

---

# Différenciation

# Erreurs fréquentes

Les élèves peuvent :

- oublier les dimensions ;

- mal aligner les solides ;

- créer des objets impossibles à fabriquer ;

- vouloir aller trop vite.

Le rappel essentiel :

> Un bon objet commence par une bonne conception.

---

# Conseils de mise en œuvre

Faire réaliser un croquis avant toute modélisation.

Inciter les élèves à mesurer.

Toujours faire tester le modèle.
