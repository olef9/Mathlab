# 💻 Scratch Découverte

> *« Scratch permet de rendre visibles les idées que l'on a déjà apprises à organiser. »*

---

# Principe

Les élèves découvrent Scratch progressivement.

Ils réinvestissent les notions travaillées en algorithmique débranchée pour construire leurs premiers programmes.

Ils apprennent à :

- déplacer un personnage ;
- utiliser des séquences ;
- employer des boucles simples ;
- utiliser des événements ;
- tester puis corriger leur programme.

L'objectif n'est pas de connaître tous les blocs de Scratch.

L'objectif est de comprendre la logique qui les relie.

---

# Pourquoi utiliser ce format ?

Scratch permet aux élèves de voir immédiatement les conséquences de leurs choix.

Ils comprennent rapidement que :

- un programme suit exactement les instructions données ;
- une erreur est souvent facile à repérer ;
- tester et corriger fait partie du travail du programmeur.

---

# Objectifs

Les élèves apprennent à :

- créer un programme simple ;
- utiliser les principaux blocs ;
- prévoir le comportement du programme ;
- déboguer ;
- améliorer leur production.

# Erreurs fréquentes

Les élèves peuvent :

- oublier un bloc ;

- placer un bloc au mauvais endroit ;

- tester trop rarement ;

- modifier plusieurs choses à la fois.

Le rappel essentiel :

> Tester souvent permet de comprendre rapidement ses erreurs.

---

# Conseils de mise en œuvre

Ne pas présenter tous les blocs.

Chaque séance doit introduire une seule nouveauté importante.

Les défis doivent rester courts et motivants.
