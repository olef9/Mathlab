# 🚀 Projet créatif

> *« Les plus beaux projets naissent souvent d'une contrainte bien choisie. »*

---

# Principe

Les élèves répondent à une mission ambitieuse en imaginant, concevant et réalisant une production originale.

Ils mobilisent les compétences développées dans les différents univers du Math'Lab.

Le projet ne consiste pas à reproduire un modèle.

Il demande de faire des choix, de résoudre des problèmes et de proposer une solution personnelle.

---

# Pourquoi utiliser ce format ?

Le projet créatif donne du sens à l'ensemble des apprentissages.

Les élèves découvrent qu'un projet complexe nécessite :

- des recherches ;
- des essais ;
- des ajustements ;
- des échanges ;
- une présentation finale.

Ils deviennent progressivement acteurs de leurs apprentissages.

---

# Objectifs

Les élèves apprennent à :

- analyser une mission ;
- respecter un cahier des charges ;
- organiser un projet ;
- coopérer ;
- améliorer une réalisation ;
- présenter leur travail.

# Les caractéristiques d'un bon projet

Un projet :

✔ répond à une mission claire ;

✔ possède plusieurs contraintes ;

✔ laisse une liberté de création ;

✔ demande plusieurs étapes ;

✔ produit une réalisation valorisable.

🎯 Concevoir un jeu mathématique original.

# Déroulement type

## 1. Mission

Comprendre le défi.

Identifier les contraintes.

Définir les critères de réussite.

---

## 2. Conception

Recherche d'idées.

Croquis.

Répartition des tâches.

Planification.

---

## 3. Réalisation

Construction progressive.

Essais.

Corrections.

Améliorations.

---

## 4. Finalisation

Contrôle du cahier des charges.

Préparation de la présentation.

---

## 5. Présentation

Chaque équipe présente :

- sa démarche ;
- les choix réalisés ;
- les difficultés rencontrées ;
- les améliorations possibles.

# Erreurs fréquentes

Les élèves peuvent :

- commencer trop vite ;

- négliger la planification ;

- oublier la mission initiale ;

- vouloir ajouter trop d'idées.

Le rappel essentiel :

> Un bon projet répond d'abord au besoin avant de chercher à impressionner.

---

# Conseils de mise en œuvre

Prévoir plusieurs points d'étape.

Faire verbaliser régulièrement les choix.

Valoriser les améliorations successives.

Conserver une trace des différentes versions du projet.
