# 🏙️ Modélisation d'un environnement

> *« Les mathématiques permettent de représenter et d'organiser le monde qui nous entoure. »*

---

# Principe

Les élèves réalisent une représentation d'un environnement réel ou imaginaire répondant à une mission.

Ils utilisent les mathématiques pour organiser l'espace, respecter des contraintes et produire une représentation cohérente.

Le support peut être :

- un plan ;
- une maquette ;
- une carte ;
- une ville ;
- un quartier ;
- un parcours ;
- un espace imaginaire.

L'objectif est de transformer une idée ou un lieu en une représentation structurée.

---

# Pourquoi utiliser ce format ?

La modélisation permet aux élèves de donner du sens à de nombreuses notions :

- repérage ;
- échelle ;
- géométrie ;
- organisation de l'espace ;
- proportions.

Ils comprennent que les mathématiques servent aussi à concevoir des espaces fonctionnels.

---

# Objectifs

Les élèves apprennent à :

- représenter un espace ;
- respecter un cahier des charges ;
- organiser les éléments ;
- utiliser les notions de géométrie et de mesure ;
- présenter leur projet.
