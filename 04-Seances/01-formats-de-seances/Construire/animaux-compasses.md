# 🐾 Animaux compassés

> *« Avec un cercle et un compas, les mathématiques prennent vie. »*

---

# Principe

Les élèves réalisent un animal ou un personnage construit principalement à partir :

- de cercles ;
- d'arcs de cercle ;
- de constructions au compas.

La création peut être réalisée à partir :

- d'un modèle ;
- de contraintes géométriques ;
- d'une création personnelle.

L'objectif est de découvrir que le compas n'est pas seulement un outil de mesure, mais un véritable outil de construction et de création.

---

# Pourquoi utiliser ce format ?

Les animaux compassés permettent de développer une relation positive avec la géométrie.

Ils montrent aux élèves que les constructions géométriques peuvent produire des réalisations originales et esthétiques.

Cette activité permet de travailler :

- la précision ;
- la maîtrise du compas ;
- l'organisation d'une figure ;
- la créativité.

Elle constitue une transition naturelle entre les constructions classiques et les créations géométriques plus complexes.

---

# Objectifs

Les élèves apprennent à :

- utiliser correctement un compas ;
- construire des cercles et des arcs ;
- conserver une ouverture de compas ;
- organiser une figure composée de plusieurs éléments ;
- créer une production géométrique.

# Déroulement type

## 1. Découverte (5 à 10 min)

Les élèves observent plusieurs exemples.

Questions possibles :

- Quelles formes reconnaissez-vous ?
- Comment les cercles ont-ils été utilisés ?
- Quels éléments donnent vie à l'animal ?

L'objectif est de faire émerger les stratégies de construction.

---

## 2. Recherche et conception (10 min)

Les élèves imaginent leur création.

Ils déterminent :

- les cercles principaux ;
- les tailles relatives ;
- l'organisation de la figure.

Ils peuvent réaliser une esquisse préalable.

---

## 3. Construction au compas (25 à 30 min)

Les élèves réalisent leur animal.

Ils travaillent :

- les centres des cercles ;
- les rayons ;
- les intersections ;
- les superpositions.

L'enseignant insiste sur :

- la précision ;
- la propreté ;
- la maîtrise du geste.

---

## 4. Présentation et valorisation (5 à 10 min)

Les élèves présentent leur réalisation.

Ils expliquent :

- les choix effectués ;
- les constructions utilisées ;
- les difficultés rencontrées.

Les productions peuvent être :

- affichées ;
- intégrées au portfolio ;
- utilisées pour une exposition.

---

# Différenciation

## Pour aider

- fournir un modèle simple ;
- proposer les centres de certains cercles ;
- limiter le nombre de constructions ;
- guider étape par étape.

---

## Pour aller plus loin

- créer un animal uniquement à partir de cercles ;
- utiliser plusieurs rayons différents ;
- rédiger une procédure de construction ;
- proposer un défi à une autre équipe.

---

# Progression possible

## 🟢 Niveau 1 — Reproduction

Les élèves reproduisent un animal existant.

Objectif :

Apprendre à utiliser le compas avec précision.

---

## 🟡 Niveau 2 — Composition

Les élèves construisent un animal avec des contraintes.

Exemples :

- utiliser au moins cinq cercles ;
- utiliser deux tailles de rayon ;
- créer une symétrie.

---

## 🟠 Niveau 3 — Construction expliquée

Les élèves rédigent les étapes nécessaires.

Objectif :

Passer de la réalisation à la communication.

---

## 🔴 Niveau 4 — Création libre

Les équipes créent un animal original.

Elles doivent fournir :

- la production ;
- les consignes ;
- les étapes de construction.

---

# Variantes possibles

## Animal mystère

Une équipe donne uniquement les instructions.

Une autre équipe tente de reconstruire l'animal.

---

## Défi symétrie

Créer un animal respectant une symétrie axiale.

---

## Galerie des constructions

Créer une exposition regroupant :

- animaux triangulés ;
- animaux compassés ;
- autres créations géométriques.

---

# Erreurs fréquentes

Les élèves peuvent rencontrer des difficultés :

- mauvaise tenue du compas ;
- ouverture du compas qui change pendant le tracé ;
- centres mal placés ;
- traits trop appuyés ;
- manque d'organisation avant de commencer.

Le message essentiel :

> La précision du geste permet à l'idée de devenir une construction.

---

# Conseils de mise en œuvre

Ce format fonctionne particulièrement bien :

- après une première découverte du compas ;
- en complément des constructions classiques ;
- avant les rosaces et pavages.

Il est important de valoriser :

- la méthode ;
- la précision ;
- la créativité.
