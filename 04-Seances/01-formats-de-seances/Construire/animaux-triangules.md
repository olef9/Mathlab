# 🐾 Animaux triangulés

> *« Avec quelques triangles, on peut donner vie aux mathématiques. »*

---

# Principe

Les élèves réalisent un animal ou un personnage entièrement construit à partir de triangles.

La figure finale peut être :

- reproduite à partir d'un modèle ;
- construite à partir de contraintes ;
- créée librement.

L'activité permet de découvrir que les formes géométriques peuvent devenir des supports de création.

---

# Pourquoi utiliser ce format ?

Les animaux triangulés permettent de faire évoluer les élèves :

de la construction géométrique vers la création.

Ils développent :

- la précision du tracé ;
- l'organisation dans l'espace ;
- l'imagination ;
- le soin de la réalisation.

C'est une activité particulièrement motivante pour les élèves de 6e et adaptée aux premières productions visibles du Math'Lab.

---

# Objectifs

Les élèves apprennent à :

- construire et assembler des triangles ;
- utiliser différentes tailles et formes ;
- organiser une composition géométrique ;
- respecter des contraintes ;
- produire une réalisation esthétique.

# Déroulement type

## 1. Découverte (5 à 10 min)

Présentation du principe.

Les élèves observent différents exemples.

Discussion :

- Quels triangles reconnaît-on ?
- Comment l'animal a-t-il été construit ?
- Quelles formes donnent l'impression de mouvement ?

---

## 2. Conception (10 min)

Avant de tracer, les élèves réalisent une esquisse.

Ils réfléchissent :

- aux différentes parties de l'animal ;
- aux tailles des triangles ;
- à l'organisation générale.

---

## 3. Construction et réalisation (25 à 30 min)

Les élèves construisent leur animal.

Ils doivent respecter les contraintes données.

Exemples :

- utiliser au moins trois types de triangles ;
- utiliser une symétrie ;
- utiliser une figure géométrique imposée ;
- construire uniquement avec des triangles.

---

## 4. Présentation (5 à 10 min)

Les élèves présentent leur création.

Ils expliquent :

- leur choix ;
- les difficultés rencontrées ;
- les constructions utilisées.

Les productions peuvent rejoindre :

- un affichage Math'Lab ;
- une exposition ;
- un portfolio.

---

# Différenciation

## Pour aider

- proposer un modèle à reproduire ;
- fournir une banque de triangles ;
- donner une silhouette à compléter ;
- limiter le nombre de contraintes.

---

## Pour aller plus loin

- imposer des contraintes géométriques supplémentaires ;
- créer un animal sans modèle ;
- rédiger les étapes de construction ;
- réaliser une fiche défi pour une autre équipe.

---

# Progression possible

## 🟢 Niveau 1 — Reproduction

Les élèves reproduisent un animal triangulé existant.

Objectif :

Maîtriser les constructions de base.

---

## 🟡 Niveau 2 — Composition

Les élèves créent un animal à partir de contraintes.

Exemples :

- utiliser un triangle équilatéral ;
- intégrer des triangles rectangles ;
- créer une symétrie.

---

## 🟠 Niveau 3 — Programme de construction

Les élèves expliquent comment réaliser leur animal.

Objectif :

Passer de la création à la communication.

---

## 🔴 Niveau 4 — Défi créatif

Les équipes créent un animal destiné à une autre équipe.

L'autre groupe doit réussir à le reproduire.

---

# Variantes possibles

## Animal mystère

Une équipe décrit son animal uniquement avec des indications géométriques.

Une autre équipe doit le construire.

---

## Galerie Math'Lab

Toutes les productions sont exposées.

Les élèves votent pour :

- la précision ;
- l'originalité ;
- la qualité géométrique.

---

## Projet collectif

Créer une grande fresque composée de nombreux animaux triangulés.

---

# Erreurs fréquentes

Les difficultés rencontrées :

- commencer sans préparer la composition ;
- utiliser des triangles sans organisation ;
- négliger la précision des tracés ;
- privilégier la décoration au détriment de la géométrie ;
- oublier les contraintes demandées.

Le message à installer :

> Une création réussie repose d'abord sur une construction réfléchie.

---

# Conseils de mise en œuvre

Cette activité fonctionne particulièrement bien :

- en début d'année pour créer une première production ;
- après les premières constructions géométriques ;
- avant une exposition.

Il est important de valoriser autant :

- la démarche ;
- la précision ;
- les choix géométriques ;

que le résultat esthétique.
