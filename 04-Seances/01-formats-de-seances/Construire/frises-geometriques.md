# 📏 Frises géométriques

> *« Un motif simple, répété avec précision, peut créer une figure étonnante. »*

---

# Principe

Les élèves observent, reproduisent puis créent des frises géométriques.

À partir d'un motif de base, ils découvrent comment construire une figure qui se répète régulièrement.

Selon le niveau, ils peuvent :

- reproduire une frise existante ;
- compléter une frise inachevée ;
- inventer une nouvelle frise ;
- rédiger les consignes permettant à une autre équipe de la reproduire.

---

# Pourquoi utiliser ce format ?

Les frises développent :

- le sens de l'observation ;
- la précision des constructions ;
- l'organisation de l'espace ;
- la recherche de régularités ;
- la créativité.

Elles permettent également de faire le lien entre les mathématiques, les arts décoratifs et l'architecture.

---

# Objectifs

Les élèves apprennent à :

- identifier un motif élémentaire ;
- reproduire une répétition régulière ;
- construire une frise soignée ;
- créer un motif original ;
- expliquer leur démarche.

# Déroulement type

## 1. Observation (5 min)

Les élèves observent plusieurs frises.

Ils recherchent :

- le motif de base ;
- les répétitions ;
- les régularités ;
- les éléments qui changent ou restent identiques.

---

## 2. Recherche (10 min)

Les élèves identifient la logique de construction.

Ils peuvent :

- compléter une frise interrompue ;
- retrouver le motif élémentaire ;
- proposer plusieurs méthodes.

---

## 3. Construction (25 à 30 min)

Les élèves reproduisent ou créent leur frise.

Ils veillent :

- à conserver les mêmes dimensions ;
- à respecter l'alignement ;
- à maintenir la régularité.

---

## 4. Valorisation (10 min)

Les productions sont présentées.

Les élèves expliquent :

- leur méthode ;
- les difficultés rencontrées ;
- les choix réalisés.

Les frises peuvent être utilisées pour décorer le Math'Lab ou illustrer un projet.

---

# Différenciation

## Pour aider

- fournir le motif de base ;
- utiliser un quadrillage ;
- limiter la longueur de la frise.

---

## Pour aller plus loin

- créer plusieurs motifs alternés ;
- utiliser des figures variées ;
- imposer des contraintes géométriques ;
- rédiger un programme de construction.

# Variantes possibles

## Frise collaborative

Chaque équipe réalise une partie d'une grande frise commune.

---

## Frise monumentale

Créer une frise destinée à décorer la classe ou le Math'Lab.

---

## Défi mystère

Une équipe crée une frise.

Une autre équipe doit retrouver le motif élémentaire et poursuivre la construction.

---

# Erreurs fréquentes

Les élèves peuvent :

- modifier progressivement les dimensions du motif ;
- perdre l'alignement ;
- oublier certains éléments du motif ;
- privilégier la décoration plutôt que la régularité.

Le rappel essentiel est :

> Une belle frise repose avant tout sur une organisation rigoureuse.

---

# Conseils de mise en œuvre

Ce format fonctionne particulièrement bien :

- après les pavages ;
- avant les programmes de construction ;
- dans un projet mêlant mathématiques et arts.

Les productions peuvent être conservées pour décorer durablement la salle ou enrichir une exposition.
