# ✍️ Programmes de construction

> *« Une bonne construction commence par une consigne claire. »*

---

# Principe

Les élèves rédigent un programme de construction permettant à une autre équipe de reproduire une figure géométrique.

L'activité peut partir :

- d'une figure imposée ;
- d'une figure créée par les élèves ;
- d'une production réalisée lors d'une séance précédente.

Les programmes sont ensuite testés par une autre équipe afin de vérifier leur précision et leur clarté.

---

# Pourquoi utiliser ce format ?

Ce format développe une compétence essentielle souvent difficile pour les élèves : **communiquer avec précision**.

Les élèves découvrent qu'une construction réussie dépend autant de la qualité des consignes que de la maîtrise des instruments.

Ils apprennent à anticiper les difficultés rencontrées par le lecteur.

---

# Objectifs

Les élèves apprennent à :

- utiliser le vocabulaire géométrique adapté ;
- organiser une suite d'instructions ;
- rédiger des consignes précises ;
- tester et améliorer un programme de construction ;
- expliquer leurs choix.

# Déroulement type

## 1. Découverte (5 min)

Présentation de l'objectif :

> Écrire un programme suffisamment précis pour qu'une autre équipe puisse reconstruire exactement la figure.

---

## 2. Rédaction (20 min)

Les élèves observent la figure.

Ils rédigent les différentes étapes.

Ils veillent à :

- respecter un ordre logique ;
- utiliser un vocabulaire précis ;
- ne rien oublier.

---

## 3. Test croisé (15 min)

Les équipes échangent leurs programmes.

Chaque groupe tente de réaliser la construction.

Les élèves notent :

- les consignes ambiguës ;
- les oublis ;
- les formulations efficaces.

---

## 4. Amélioration (10 min)

Les auteurs corrigent leur programme.

Ils expliquent les modifications apportées.

---

# Différenciation

## Pour aider

- fournir une banque de vocabulaire ;
- proposer une figure simple ;
- compléter un programme partiellement rédigé.

---

## Pour aller plus loin

- rédiger plusieurs méthodes possibles ;
- construire sans illustration ;
- écrire un programme volontairement incomplet puis le faire améliorer ;
- créer un défi pour une autre équipe.

---

# Progression possible

## 🟢 Niveau 1 — Compléter

Compléter un programme déjà commencé.

---

## 🟡 Niveau 2 — Décrire

Rédiger le programme d'une figure simple.

---

## 🟠 Niveau 3 — Tester

Faire construire la figure par une autre équipe et améliorer le texte.

---

## 🔴 Niveau 4 — Concevoir

Créer une figure originale et rédiger un programme complet permettant sa reproduction.

---

# Variantes possibles

## Défi mystère

Une équipe ne possède que le programme.

Elle découvre la figure uniquement au moment de la construction.

---

## Programme à corriger

Les élèves reçoivent un programme comportant des erreurs.

Ils doivent les identifier puis proposer une version améliorée.

---

## Banque de défis

Les meilleurs programmes sont conservés pour les classes suivantes.

---

# Erreurs fréquentes

Les élèves peuvent :

- oublier certaines informations ;
- employer un vocabulaire imprécis ;
- écrire plusieurs actions dans une même consigne ;
- inverser certaines étapes ;
- supposer que le lecteur « devinera ».

Le message essentiel :

> Un bon programme est compris de la même manière par tous les lecteurs.

---

# Conseils de mise en œuvre

Ce format prend tout son sens lorsqu'il s'appuie sur une construction déjà réalisée par les élèves.

Le **test croisé** est indispensable : c'est lui qui fait prendre conscience de l'importance de la précision.

# Place dans le Math'Lab

Ce format fait évoluer les élèves d'exécutants vers concepteurs.

Ils découvrent qu'en mathématiques, savoir **expliquer** est aussi important que savoir **faire**.

> Une figure bien construite est le résultat d'un programme clair, précis et compréhensible.
