# 📐 Construction IREM Paris Nord

> *« Construire, c'est réfléchir avant de tracer. »*

---

# Principe

Les élèves réalisent une construction géométrique à partir :

- d'une figure modèle ;
- d'une consigne ;
- d'un programme de construction ;
- ou d'un défi proposé.

L'objectif n'est pas seulement d'obtenir une figure correcte, mais de comprendre les étapes nécessaires pour y parvenir.

Les élèves apprennent à observer, analyser, construire, vérifier et expliquer.

---

# Pourquoi utiliser ce format ?

La construction géométrique constitue une activité fondamentale du Math'Lab.

Elle permet d'installer des habitudes essentielles :

- prendre le temps d'observer ;
- réfléchir avant d'agir ;
- utiliser les instruments avec précision ;
- accepter l'erreur et corriger ;
- expliquer sa démarche.

Ce format est particulièrement adapté au début de l'année pour installer une culture commune du travail géométrique.

---

# Objectifs

Les élèves apprennent à :

- maîtriser progressivement les instruments de géométrie ;
- respecter une démarche de construction ;
- développer leur précision ;
- analyser une figure ;
- communiquer une méthode ;
- vérifier un résultat.

# Déroulement type

## 1. Observation et analyse (5 min)

Les élèves découvrent la figure ou la consigne.

Avant de tracer, ils doivent identifier :

- les éléments connus ;
- les relations entre les éléments ;
- l'ordre possible des constructions.

---

## 2. Recherche et construction (25 à 30 min)

Les élèves réalisent la construction.

Ils peuvent :

- faire des essais ;
- comparer leurs démarches ;
- demander une validation ;
- corriger leurs erreurs.

L'enseignant accompagne par des questions :

- « Qu'observes-tu ? »
- « Quelle propriété peux-tu utiliser ? »
- « Comment vérifier ton résultat ? »

---

## 3. Analyse des productions (10 à 15 min)

La classe compare plusieurs réalisations.

On observe :

- les méthodes utilisées ;
- les choix efficaces ;
- les erreurs intéressantes.

L'objectif est de comprendre les démarches, pas uniquement de corriger.

---

# Différenciation

## Pour aider

- proposer une figure moins complexe ;
- donner une étape intermédiaire ;
- fournir un programme partiellement complété ;
- permettre une construction accompagnée.

---

## Pour aller plus loin

- rédiger le programme de construction ;
- construire sans modèle ;
- modifier une figure en respectant certaines contraintes ;
- créer une figure pour une autre équipe.

---

# Progression possible

## 🟢 Niveau 1 — Reproduire

Objectif :

Découvrir les instruments et apprendre les gestes de base.

Exemples :

- reproduire une figure simple ;
- tracer des segments ;
- utiliser le compas.

---

## 🟡 Niveau 2 — Construire avec contraintes

Objectif :

Comprendre une démarche.

Exemples :

- construire une figure connaissant certaines mesures ;
- utiliser des propriétés géométriques.

---

## 🟠 Niveau 3 — Expliquer

Objectif :

Communiquer une méthode.

Exemples :

- rédiger un programme de construction ;
- expliquer une stratégie.

---

## 🔴 Niveau 4 — Créer

Objectif :

Devenir concepteur.

Exemples :

- inventer une figure ;
- proposer un défi à une autre équipe.

---

# Variantes possibles

## Défi précision

Toutes les équipes réalisent la même construction.

Critères :

- exactitude ;
- soin ;
- méthode.

---

## Défi communication

Une équipe possède le modèle.

Elle doit expliquer oralement la construction à une autre équipe.

---

## Défi création

Chaque équipe imagine une nouvelle construction.

Elle doit fournir :

- la figure ;
- les consignes ;
- la solution.

---

# Erreurs fréquentes

Les difficultés rencontrées sont souvent :

- commencer à tracer trop vite ;
- ne pas analyser la figure avant de commencer ;
- utiliser les instruments sans précision ;
- déplacer la règle ou l'équerre pendant le tracé ;
- mesurer systématiquement sans chercher les propriétés ;
- ne pas vérifier son travail.

Le message essentiel à installer :

> La réussite vient d'une bonne méthode, pas de la vitesse.

---

# Conseils de mise en œuvre

Les premières utilisations doivent installer les habitudes du Math'Lab :

- prendre soin du matériel ;
- travailler proprement ;
- réfléchir avant de tracer ;
- expliquer ses choix ;
- accepter les corrections.

Ces habitudes seront réutilisées dans toutes les activités géométriques.
