# 🌸 Rosaces géométriques

> *« Une figure simple peut devenir une œuvre remarquable lorsqu'elle est construite avec précision. »*

---

# Principe

Les élèves réalisent des rosaces géométriques à partir de constructions au compas.

Selon le niveau, ils peuvent :

- reproduire une rosace ;
- compléter une rosace inachevée ;
- créer une rosace originale ;
- expliquer ou rédiger son programme de construction.

Les productions peuvent ensuite être coloriées ou exposées.

---

# Pourquoi utiliser ce format ?

Les rosaces permettent de travailler les constructions géométriques dans un contexte motivant.

Les élèves comprennent progressivement que des figures complexes peuvent être obtenues en répétant des constructions simples.

Cette activité développe :

- la précision ;
- la patience ;
- le sens de l'observation ;
- l'organisation du travail.

---

# Objectifs

Les élèves apprennent à :

- maîtriser le compas ;
- conserver un rayon constant ;
- construire des cercles et des arcs ;
- repérer des régularités ;
- produire une figure précise et soignée.

# Déroulement type

## 1. Observation (5 min)

Les élèves observent plusieurs rosaces.

Ils recherchent :

- les cercles utilisés ;
- les répétitions ;
- les symétries ;
- les centres de construction.

---

## 2. Construction (30 min)

Les élèves réalisent la rosace.

Ils vérifient régulièrement :

- la précision des tracés ;
- la conservation du rayon ;
- l'alignement des constructions.

L'enseignant accompagne les groupes par questionnement sans réaliser les tracés à leur place.

---

## 3. Mise en valeur (10 à 15 min)

Les productions sont observées collectivement.

Les élèves expliquent :

- les difficultés rencontrées ;
- les méthodes utilisées ;
- les régularités découvertes.

Un coloriage peut être réalisé pour mettre en évidence les symétries ou les motifs.

---

# Différenciation

## Pour aider

- fournir un cercle déjà tracé ;
- proposer certains points de construction ;
- limiter le nombre d'étapes.

---

## Pour aller plus loin

- construire une rosace sans modèle ;
- modifier une rosace existante ;
- créer un motif personnel ;
- rédiger un programme de construction.

# Variantes possibles

## Rosace collaborative

Chaque équipe réalise une partie d'une grande rosace.

Les productions sont ensuite assemblées.

---

## Rosace géante

Construire une rosace au sol dans la cour à la craie ou avec des cordes.

---

## Défi symétrie

Créer une rosace répondant à une contrainte de symétrie ou de rotation.

---

# Erreurs fréquentes

Les élèves peuvent :

- modifier involontairement l'ouverture du compas ;
- changer le centre de construction ;
- tracer des arcs incomplets ;
- appuyer trop fort sur le crayon ;
- vouloir aller trop vite.

Le rappel essentiel est :

> Une rosace réussie est avant tout une construction précise.

---

# Conseils de mise en œuvre

Cette activité est idéale :

- après les animaux compassés ;
- avant les pavages ;
- pour préparer une exposition.

Il est préférable de laisser aux élèves un temps d'observation avant toute construction.
