# 📝 Produire un support de communication

> *« Un bon support aide les autres à comprendre sans avoir besoin de longues explications. »*

---

# Principe

Les élèves réalisent un support destiné à transmettre une idée, une méthode ou une production.

Ils doivent sélectionner les informations essentielles et les organiser de manière claire.

Le support peut être :

- une affiche ;
- une fiche méthode ;
- un tutoriel ;
- une carte mentale ;
- une infographie ;
- une légende d'exposition ;
- une présentation numérique.

---

# Pourquoi utiliser ce format ?

Créer un support oblige les élèves à réfléchir à ce qui est vraiment important.

Ils apprennent à :

- organiser les informations ;
- hiérarchiser les idées ;
- utiliser des représentations efficaces ;
- adapter leur production au public.

---

# Objectifs

Les élèves apprennent à :

- communiquer autrement que par l'oral ;

- rendre une information claire ;

- illustrer une idée mathématique ;

- produire un document utile.

# Erreurs fréquentes

Les élèves peuvent :

- vouloir tout écrire ;

- oublier les illustrations ;

- produire un document difficile à lire.

Le rappel essentiel :

> Un bon support permet de comprendre rapidement l'essentiel.
