# 🎤 Communication orale

> *« Une idée claire mérite une explication claire. »*

---

# Principe

Les élèves prennent la parole pour présenter, expliquer ou convaincre.

Ils adaptent leur discours à la mission et au public.

Ils apprennent progressivement à :

- organiser leurs idées ;
- utiliser un vocabulaire mathématique précis ;
- parler avec assurance ;
- répondre aux questions.

---

# Pourquoi utiliser ce format ?

Prendre la parole permet aux élèves de structurer leur pensée.

Ils découvrent que communiquer ne consiste pas à réciter un texte, mais à faire comprendre une idée.

---

# Objectifs

Les élèves apprennent à :

- préparer une intervention ;

- parler devant un groupe ;

- illustrer leurs explications ;

- répondre aux questions.

# Déroulement type

## 1. Préparation

Organisation des idées.

Répartition de la parole.

---

## 2. Présentation

Chaque équipe réalise son intervention.

---

## 3. Questions

Le public interroge.

Les élèves répondent.

---

## 4. Retour

Analyse collective :

- ce qui était clair ;
- ce qui pourrait être amélioré.

# Erreurs fréquentes

Les élèves peuvent :

- lire leurs notes ;

- parler trop vite ;

- oublier les schémas ;

- répondre sans réfléchir.

Le rappel essentiel :

> Parler moins... mais faire mieux comprendre.
