# 🗣️ Présenter une démarche

> *« En mathématiques, expliquer comment on a trouvé est souvent aussi important que la réponse elle-même. »*

---

# Principe

Les élèves présentent à la classe une démarche, une stratégie ou une production.

Ils ne cherchent pas uniquement à donner le résultat.

Ils expliquent :

- ce qu'ils ont fait ;
- pourquoi ils l'ont fait ;
- ce qu'ils ont appris.

L'objectif est de rendre leur raisonnement compréhensible.

---

# Pourquoi utiliser ce format ?

Présenter une démarche oblige les élèves à organiser leur pensée.

Ils découvrent que :

- expliquer aide à mieux comprendre ;
- plusieurs stratégies peuvent être pertinentes ;
- un raisonnement doit être clair pour convaincre.

---

# Objectifs

Les élèves apprennent à :

- organiser leurs idées ;
- utiliser un vocabulaire mathématique précis ;
- justifier leurs choix ;
- répondre aux questions de leurs camarades.

# Compétences travaillées

## Compétences mathématiques

### Communiquer

- expliquer une démarche ;
- utiliser un langage précis.

### Raisonner

- justifier un choix.

### Représenter

- utiliser un schéma, un tableau ou une figure pour soutenir les explications.

---

## Compétences du Math'Lab

- confiance en soi ;
- écoute ;
- esprit de synthèse ;
- précision.

---

# Les caractéristiques d'une bonne présentation

Une bonne présentation :

✔ répond à la mission ;

✔ suit un fil logique ;

✔ utilise des représentations adaptées ;

✔ met en évidence les choix réalisés ;

✔ reste compréhensible pour tous.

---

# Exemples de missions

🎯 Présenter une stratégie de résolution.

🎯 Expliquer une construction géométrique.

🎯 Décrire le fonctionnement d'un programme Scratch.

🎯 Justifier une méthode de calcul.

🎯 Présenter une création géométrique.

---

# Déroulement type

## 1. Préparation (10 min)

Les élèves organisent leurs idées.

Ils choisissent les informations essentielles.

---

## 2. Présentation (5 min)

Chaque équipe présente sa démarche.

---

## 3. Questions (10 min)

Les autres élèves demandent des précisions.

Ils cherchent à comprendre.

---

## 4. Synthèse (10 min)

La classe identifie :

- les points forts ;
- les différentes stratégies ;
- les idées importantes.

---

# Différenciation

## Pour aider

- fournir une trame de présentation ;
- proposer quelques questions-guides ;
- autoriser un support visuel.

---

## Pour aller plus loin

- limiter le temps de parole ;
- présenter sans notes ;
- comparer plusieurs démarches.

# Erreurs fréquentes

Les élèves peuvent :

- raconter toutes les étapes sans sélectionner l'essentiel ;

- oublier de justifier leurs choix ;

- lire leurs notes.

Le rappel essentiel :

> Présenter, ce n'est pas tout dire. C'est faire comprendre l'essentiel.

---

# Conseils de mise en œuvre

Encourager les schémas.

Valoriser les explications simples.

Faire reformuler les idées par d'autres élèves.

# Place dans le Math'Lab

Présenter une démarche permet aux élèves de transformer une réflexion personnelle en une explication claire et structurée.

> **Une démarche bien expliquée permet aux autres d'apprendre autant que celui qui la présente.**
