# RALLYE-02 – Deux pommes, trois pains express

## Code

On utilise quatre symboles :

| Symbole | Il représente |
|---|---|
| `PO` | une pomme |
| `PA` | un pain |
| `PDP` | une pomme et deux pains |
| `CDP` | deux pommes |

---

# Question 1

Une carte contient :

```text
PDP + CDP + PA + PA
```

Combien représente-t-elle de pommes et de pains ?

## Réponse

```text
PDP = 1 pomme et 2 pains
CDP = 2 pommes
PA + PA = 2 pains
```

Total :

```text
3 pommes et 4 pains
```

---

# Question 2

Compléter avec un seul symbole :

```text
PDP + PA + ______
```

pour obtenir :

```text
3 pommes et 3 pains
```

## Réponse

Les symboles déjà présents représentent :

```text
1 pomme et 3 pains
```

Il manque :

```text
2 pommes et 0 pain
```

Donc :

```text
CDP
```

---

# Question 3 – Bonus

Compléter avec un seul symbole :

```text
PO + PDP + ______
```

pour obtenir :

```text
3 pommes et 4 pains
```

## Réponse

Les symboles présents représentent :

```text
2 pommes et 2 pains
```

Il manque :

```text
1 pomme et 2 pains
```

Donc :

```text
PDP
```
