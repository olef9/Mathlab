# Le renard triangulé – Repères enseignant

## Finalité

Cette activité combine reproduction géométrique et création sous contraintes.

Elle ne doit pas devenir un simple coloriage. La priorité reste :

- l'analyse du modèle ;
- la précision des tracés ;
- l'organisation de la construction ;
- la transformation réfléchie de la figure.

---

# Lecture du modèle

Le renard est construit sur un réseau triangulaire.

Les élèves peuvent utilement repérer :

- les deux pointes des oreilles ;
- le sommet situé entre les oreilles ;
- l'axe central du front ;
- les deux zones correspondant aux yeux ;
- les deux côtés du museau ;
- la pointe inférieure du visage.

Le modèle comporte volontairement plusieurs triangles de tailles différentes.

---

# Ordre possible de reproduction

Il n'existe pas un ordre unique.

Une procédure efficace consiste à :

1. tracer le contour extérieur du visage ;
2. placer le sommet central entre les oreilles ;
3. tracer l'axe du front vers le museau ;
4. construire les deux grandes zones latérales ;
5. ajouter les lignes des yeux et des joues ;
6. terminer par les triangles du museau ;
7. vérifier les deux moitiés de la figure.

Cette procédure est une aide pour l'enseignant, pas un programme à distribuer.

---

# Progression des aides

## Aide 1 – Lire le contour

> Peux-tu suivre tout le contour du renard avec ton doigt sans passer par l'intérieur ?

## Aide 2 – Repérer l'axe

> Quels sommets sont situés au milieu du visage ?

## Aide 3 – Décomposer

> Commence par les oreilles et le contour. Tu ajouteras les triangles intérieurs ensuite.

## Aide 4 – Donner trois points de départ

Signaler :

- le sommet central supérieur ;
- le centre du front ;
- la pointe du museau.

## Aide 5 – Contour prétracé

Fournir une version adaptée où seul le contour extérieur est déjà réalisé.

L'élève complète le réseau intérieur.

---

# Erreurs fréquentes

## Commencer par les petits détails

L'élève risque de décaler toute la figure.

L'inviter à construire d'abord le contour et les grandes lignes.

## Relier des points qui ne le sont pas dans le modèle

Faire comparer segment par segment, sans donner toute la correction.

## Rechercher une symétrie parfaite

Le modèle est très proche d'une organisation symétrique, mais l'élève doit s'appuyer sur les points du réseau plutôt que sur une construction instrumentée de symétrie.

## Colorier trop tôt

Le coloriage masque parfois les erreurs et consomme le temps consacré à la transformation.

## Transformer sans respecter les contraintes

Faire vérifier la liste :

- quatre segments modifiés ;
- dix triangles visibles ;
- aucune courbe ;
- une partie du renard conservée.

---

# Validation de la reproduction

La reproduction est considérée comme satisfaisante lorsque :

- le contour est fermé ;
- les deux oreilles sont reconnaissables ;
- l'axe central est présent ;
- les zones principales sont triangulées ;
- les segments passent par les points du réseau ;
- aucun segment majeur n'est oublié.

Une petite différence de proportion ne doit pas bloquer l'entrée dans la phase créative.

---

# Validation de la création

La création respecte la mission lorsque :

- elle représente un animal réel ou imaginaire ;
- elle reste construite uniquement avec des segments ;
- elle contient au moins dix triangles ;
- au moins quatre segments du modèle ont été modifiés ;
- une partie de la structure du renard reste identifiable ;
- l'élève peut expliquer ses choix.

---

# Bilan conseillé

Faire comparer deux démarches :

- reproduire le plus fidèlement possible ;
- modifier volontairement en respectant des contraintes.

Question centrale :

> En quoi les contraintes vous ont-elles aidés à créer ?

Idées à faire émerger :

- une contrainte évite la page blanche ;
- la même structure peut produire plusieurs résultats ;
- observer une figure permet de mieux la transformer ;
- la précision et la créativité ne s'opposent pas.
