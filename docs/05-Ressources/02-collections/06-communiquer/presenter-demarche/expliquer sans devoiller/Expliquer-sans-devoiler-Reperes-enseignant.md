# Expliquer sans dévoiler – Repères enseignant

## Finalité

Cette séance constitue la première véritable entrée dans l'univers **Communiquer**.

Les élèves ne doivent pas simplement raconter une ancienne séance. Ils apprennent à construire une aide adaptée à un destinataire.

La compétence centrale est :

> sélectionner une information suffisamment utile pour faire progresser, mais pas assez complète pour supprimer la recherche.

---

# Choix des sujets

Pour quatre équipes, utiliser de préférence :

- Hextoile ;
- Pentominos ;
- Robot maladroit ;
- Trioz.

Le renard triangulé peut servir :

- de cinquième carte ;
- de remplacement pour un groupe ayant rencontré des difficultés importantes avec Trioz ;
- de sujet supplémentaire lors d'une reprise.

Il est préférable que chaque groupe travaille sur une activité différente.

---

# Attribution des cartes

Deux méthodes sont possibles.

## Attribution par l'enseignant

Permet d'équilibrer la difficulté.

- Trioz : groupe capable de sélectionner des informations abstraites ;
- Hextoile : groupe précis dans le vocabulaire géométrique ;
- Robot : groupe à l'aise avec une démonstration gestuelle ;
- Pentominos : groupe capable de parler d'organisation et de doublons ;
- Renard : groupe ayant besoin d'un support très visuel.

## Tirage au sort

Possible lorsque les équipes fonctionnent déjà bien.

Prévoir toutefois un échange si un groupe n'a pas suffisamment compris la séance attribuée.

---

# La frontière entre aide et solution

## Aide trop faible

```text
Réfléchissez bien.
Essayez plusieurs choses.
Observez la figure.
```

Ces phrases sont vraies, mais peu opérationnelles.

## Aide utile

```text
Pour Hextoile, cherchez d'abord les alignements qui continuent après un point.
```

Cette phrase oriente la recherche sans donner les tracés.

## Solution dévoilée

```text
Tracez d'abord telle droite, puis telle demi-droite : leur intersection est la première pointe.
```

Cette formulation donne déjà une étape précise de la correction.

---

# Critères de réussite

Une présentation réussie :

- nomme clairement le but ;
- utilise un vocabulaire compréhensible ;
- propose une stratégie précise ;
- signale une erreur fréquente ;
- ne révèle pas la réponse ;
- respecte le temps ;
- répartit la parole ;
- utilise un support simple.

La qualité de l'explication compte davantage que la beauté du support.

---

# Progression des aides

## Aide 1 – Identifier le destinataire

> Qu'est-ce qu'un élève qui n'a jamais fait cette activité ne peut pas encore savoir ?

## Aide 2 – Choisir un seul obstacle

> Quel est le premier blocage rencontré par la majorité des élèves ?

## Aide 3 – Transformer la correction en question

Au lieu de donner une étape, formuler :

> Que faut-il prolonger pour faire apparaître un nouveau point ?

## Aide 4 – Utiliser un autre exemple

Pour Trioz, créer un mini-compteur différent des nombres demandés dans la fiche.

Pour le robot, utiliser un parcours de trois cases qui n'est pas celui de la séance.

## Aide 5 – Script allégé

Donner uniquement :

```text
Votre mission…
Pour commencer…
Attention à…
À vous de chercher…
```

# Erreurs fréquentes

## Raconter toute la séance

Faire recentrer sur ce dont le destinataire a besoin pour commencer.

## Lire un texte intégral

Demander des mots-clés sur une petite fiche plutôt qu'un paragraphe complet.

## Montrer la correction

Masquer les réponses, utiliser un exemple partiel ou une autre situation.

## Employer un vocabulaire non expliqué

Exemples :

- base 3 ;
- programme ;
- demi-droite ;
- rotation.

Demander soit de définir le mot, soit d'utiliser une formulation plus accessible.

## Un élève parle seul

Imposer une répartition minimale de la parole.

## Support surchargé

Limiter à :

- un titre ;
- trois mots-clés ;
- un schéma ou exemple ;
- une erreur à éviter.

---

# Feedback entre équipes

Le retour doit rester précis et bienveillant.

Faire utiliser obligatoirement :

```text
J'ai bien compris…
J'aurais besoin de préciser…
Vous dévoilez peut-être trop lorsque…
```

Refuser les retours vagues :

```text
C'était bien.
Parlez plus fort.
Ce n'était pas clair.
```

Les remarques sur la voix peuvent être ajoutées, mais elles ne remplacent pas l'analyse du contenu.

---

# Gestion du temps

La durée des présentations peut dépasser le temps prévu si cinq équipes interviennent.

Solutions :

- limiter strictement à 60 secondes ;
- présenter trois groupes devant toute la classe et deux en binômes ;
- enregistrer seulement l'audio de deux équipes pour une écoute ultérieure ;
- poursuivre au début de S07 sans refaire toute la préparation.

Ne pas supprimer la répétition croisée : elle constitue le cœur de l'amélioration.

---

# Première approche de la vidéo

Cette séance prépare la production vidéo sans imposer immédiatement :

- le cadrage ;
- le montage ;
- la publication ;
- les autorisations ;
- la gestion du son.

Une équipe peut être filmée uniquement pour observer sa prestation, puis la vidéo est supprimée après le retour.

La première vraie capsule destinée au patrimoine Math'Lab pourra être produite plus tard, lorsque les élèves maîtriseront mieux :

- la structure d'une explication ;
- la durée ;
- la répartition de la parole ;
- la distinction entre aide et solution.

# Bilan conseillé

Écrire au tableau deux axes :

```text
UTILE  ←────────────→  INUTILE
PRÉSERVE LA RECHERCHE  ←────────────→  DONNE LA SOLUTION
```

Placer quelques exemples de conseils sur ces deux axes.

Faire émerger qu'une bonne explication se situe :

- du côté utile ;
- mais sans atteindre la solution complète.

Synthèse :

> Communiquer une démarche, ce n'est pas réciter une correction.  
> C'est permettre à quelqu'un d'avancer par lui-même.
