# S14 – Capsules minute : transmettre une démarche

## Idée générale

Cette séance clôt la première période par la réalisation des **premières capsules vidéo du Math'Lab**.

Chaque équipe reprend une activité déjà rencontrée et prépare une capsule courte destinée à un futur élève de sixième.

La capsule ne doit pas réciter toute la solution. Elle doit permettre de comprendre :

- la mission ;
- la démarche utile ;
- une difficulté fréquente ;
- un conseil précis ;
- ce que l'activité apprend à faire.

La séance prolonge directement **S06 – Expliquer sans dévoiler**. Cette fois, l'explication est enregistrée, cadrée et conservée dans le patrimoine du Math'Lab.

---

# Production attendue

Une vidéo de :

```text
1 minute 30 à 2 minutes 30
```

La capsule doit pouvoir être comprise :

- sans l'enseignant ;
- sans connaître l'activité à l'avance ;
- avec le son ou avec un support visuel suffisamment explicite ;
- sans révéler inutilement toutes les réponses.

## Format conseillé

Pour cette première expérience :

- une seule prise autant que possible ;
- plan fixe ;
- appareil en position horizontale ;
- uniquement les mains et le support filmés ;
- pas de prénom ni de nom de famille ;
- aucun montage obligatoire ;
- aucun fond musical ;
- titre annoncé au début ;
- support original ou reproduction autorisée uniquement dans le cadre interne de la classe.

# Mission du jour

> Préparez une capsule vidéo courte qui permette à un futur élève de comprendre une démarche du Math'Lab et d'avoir envie de l'essayer.

## La capsule doit contenir

1. le nom de la mission ;
2. le but en une phrase ;
3. le matériel ou le support utile ;
4. une démarche pour commencer ;
5. une difficulté fréquente ;
6. un conseil précis ;
7. une phrase de conclusion.

## La capsule ne doit pas contenir

- une lecture intégrale de la fiche ;
- toutes les réponses ;
- une correction complète à recopier ;
- une longue introduction ;
- des noms d'élèves ;
- une plaisanterie qui empêche de comprendre ;
- une musique couvrant la voix ;
- un visage filmé sans cadre prévu par l'établissement ;
- une image ou un document destiné à une diffusion publique sans autorisation.

---

# Activités proposées

L'enseignant choisit quatre ou cinq cartes selon le nombre d'équipes.

## Carte A – Hextoile

Expliquer :

- pourquoi il faut observer avant de tracer ;
- comment les intersections créent de nouveaux points ;
- une erreur fréquente avec les segments et les demi-droites.

Ne pas montrer la construction entière étape par étape.

## Carte B – Les pentominos

Expliquer :

- la règle de formation ;
- comment éviter les doublons obtenus par rotation ou retournement ;
- une stratégie de classement.

Ne pas donner immédiatement les douze formes.

## Carte C – La numération des Trioz

Expliquer :

- qu'il s'agit d'un autre système de numération ;
- comment observer les régularités ;
- comment vérifier une traduction.

Ne pas afficher toutes les conversions finales.

## Carte D – Le programme saboté

Expliquer la méthode :

```text
exécuter → repérer le premier écart → corriger une instruction → retester
```

Ne présenter qu'un seul bug très court.

## Carte E – Le coffre des quatre verrous

Expliquer :

- pourquoi les experts doivent coopérer ;
- comment partager les résultats ;
- comment vérifier un ordre logique.

Ne pas annoncer le code du coffre.

## Carte F – Échecs : capturer ou protéger ?

Expliquer :

```text
capture → reprise → bilan
```

Utiliser une position simple et comparer les valeurs des pièces.

## Carte G – La tuile transformée

Expliquer :

- la découpe d'un bord ;
- la translation de la pièce ;
- pourquoi elle ne doit être ni tournée ni retournée ;
- l'absence de trou et de chevauchement.

## Carte H – Le programme de construction inversé

Expliquer :

- pourquoi une consigne doit être précise ;
- comment nommer les points ;
- comment un testeur révèle une ambiguïté.

Présenter une version avant et après correction.

# Organisation des équipes

Équipes stables de trois ou quatre élèves.

## Rôles

### 1. Présentateur

- annonce le titre ;
- explique la mission ;
- assure les transitions.

### 2. Démonstrateur

- manipule le support ;
- montre un exemple ;
- évite de masquer la figure.

### 3. Gardien du temps et de la précision

- surveille la durée ;
- vérifie le vocabulaire ;
- signale les phrases trop longues.

### 4. Réalisateur

- installe le cadre ;
- lance et arrête l'enregistrement ;
- vérifie rapidement le son et l'image.

Dans une équipe de trois, le présentateur peut aussi être gardien du temps.

Tous les élèves doivent intervenir dans la préparation. Il n'est pas obligatoire que tous parlent dans la version filmée.

---

# Préparation de l'enseignant

## Matériel

- un ou deux appareils d'enregistrement ;
- un support stable ou un petit trépied ;
- les cartes missions ;
- une fiche script par équipe ;
- un storyboard facultatif ;
- un chronomètre ;
- les productions des séances précédentes ;
- une zone calme de tournage ;
- des écouteurs pour vérifier rapidement le son, si disponibles.

## Avant la séance

- sélectionner les activités attribuées ;
- ressortir uniquement les supports nécessaires ;
- créer les dossiers de destination ;
- charger les appareils ;
- libérer l'espace de stockage ;
- désactiver les notifications pendant l'enregistrement ;
- préparer l'ordre de passage ;
- vérifier les règles de l'établissement concernant l'image, la voix et la diffusion ;
- privilégier pour cette première séance un cadrage sur les mains et les productions.

## Diffusion

Par défaut, les capsules sont destinées à un **usage pédagogique interne**.

Toute diffusion plus large nécessite le respect des autorisations et règles de l'établissement.

# Déroulement détaillé

## 1. Rituel Rallye – 6 minutes

Utiliser :

**RALLYE-02 – Deux pommes, trois pains express**

Le rituel demande de traduire des symboles en quantités puis de retrouver un symbole manquant.

Correction rapide, avec une seule explication détaillée.

---

## 2. Regarder un mauvais et un bon départ – 4 minutes

Lire deux introductions :

### Introduction trop longue

> Bonjour, aujourd'hui nous allons vous présenter une activité que nous avons faite il y a quelque temps et que nous avons trouvée assez intéressante...

### Introduction efficace

> Notre mission s'appelle « Le programme saboté ». Nous allons vous montrer comment repérer la première instruction qui provoque une erreur.

Questions :

- Laquelle donne immédiatement le sujet ?
- Laquelle permet de gagner du temps ?
- Quelle information est essentielle ?

---

## 3. Attribution des missions et rappel de S06 – 4 minutes

Distribuer les cartes.

Rappeler la structure travaillée en S06 :

```text
but → stratégie → difficulté → conseil
```

Ajouter aujourd'hui :

```text
support visible → voix audible → durée maîtrisée
```

---

## 4. Écriture du script – 10 minutes

Chaque équipe complète la fiche script.

La capsule est découpée en cinq blocs :

| Bloc | Durée indicative |
|---|---:|
| Titre et mission | 15 s |
| Ce qu'il faut comprendre | 20 s |
| Démonstration d'une démarche | 45 à 60 s |
| Erreur fréquente et conseil | 25 s |
| Conclusion | 10 s |

## Règle d'écriture

Ne pas rédiger chaque phrase intégralement.

Utiliser :

- des mots-clés ;
- les expressions mathématiques nécessaires ;
- l'ordre des interventions ;
- les objets à montrer.

Une lecture mot à mot produit souvent une capsule moins naturelle.

---

## 5. Répétition chronométrée – 7 minutes

Chaque équipe réalise deux essais sans filmer.

### Premier essai

Objectif : aller jusqu'au bout.

### Retour express

Un autre groupe répond :

- ce que nous avons compris ;
- ce qui manque ;
- ce qui est trop long ;
- le mot ou le geste le plus utile.

### Deuxième essai

Objectif : respecter la durée et améliorer un point précis.

Une équipe n'entre pas dans la zone de tournage avant d'avoir réalisé un essai compris entre :

```text
1 min 20 et 2 min 40
```

---

## 6. Tournage en rotation – 16 minutes

Utiliser le plan de tournage.

### Avec un seul appareil

Prévoir environ trois minutes par équipe :

- 30 secondes d'installation ;
- 2 minutes de prise ;
- 30 secondes de vérification.

Pendant qu'une équipe filme :

- l'équipe suivante prépare le support ;
- les autres finalisent leur répétition ;
- une équipe déjà filmée remplit la grille d'autoévaluation.

### Avec deux appareils

Créer deux zones :

```text
Zone A – constructions et pavages
Zone B – énigmes, algorithmique ou échecs
```

## Règle de reprise

Une seconde prise est autorisée seulement si :

- le son est inutilisable ;
- l'enregistrement s'est arrêté ;
- une information importante est fausse ;
- la capsule dépasse largement la durée ;
- le support n'est pas visible.

Un simple hésitation n'impose pas de recommencer.

---

## 7. Visionnage ciblé – 5 minutes

Visionner seulement deux ou trois capsules pendant la séance.

Pour chaque capsule, demander :

1. Une chose claire.
2. Une chose utile.
3. Une amélioration précise.

Ne pas faire une correction publique de tous les défauts.

Les autres capsules pourront être regardées lors d'un temps ultérieur ou par l'enseignant.

---

## 8. Bilan et archivage – 3 minutes

Chaque équipe nomme son fichier selon le modèle :

```text
S14_Equipe-__Activite_Prise-1
```

Exemples :

```text
S14_Equipe-2_Pavage_Prise-1
S14_Equipe-4_Echecs_Prise-2
```

Déposer dans le dossier correspondant.

Phrase de bilan :

> Une capsule utile n'est pas celle qui montre tout. C'est celle qui choisit ce qu'il faut montrer pour faire comprendre une démarche.

# Différenciation

## Aide légère

Donner les cinq débuts de phrases :

```text
Notre mission consiste à…
Pour commencer, il est utile de…
Une erreur fréquente est…
Notre conseil est…
Cette activité apprend à…
```

## Aide intermédiaire

Fournir le script dans le désordre et demander de remettre les parties dans un ordre efficace.

## Aide renforcée

- limiter la capsule à 60 ou 90 secondes ;
- autoriser une voix hors champ unique ;
- fournir un support déjà préparé ;
- demander seulement : mission, stratégie, erreur, conseil ;
- filmer l'enseignant tenant l'appareil au-dessus du support.

## Élèves rapides

- préparer un titre écrit de cinq secondes ;
- ajouter une question finale au spectateur ;
- produire une version de 45 secondes sans perdre l'idée essentielle ;
- sous-titrer manuellement trois mots-clés sur une carte visible ;
- préparer une seconde capsule sur une activité différente ;
- analyser une capsule et proposer un découpage plus efficace.

---

# Observation de l'enseignant

Observer notamment :

- la sélection des idées ;
- la différence entre expliquer et réciter ;
- la répartition des rôles ;
- le respect du temps ;
- la qualité du vocabulaire ;
- l'utilisation du support ;
- la capacité à accepter un retour ;
- l'autonomie technique ;
- le respect des règles liées à l'image et à la diffusion.

La qualité technique attendue reste modeste. L'objectif principal est une explication mathématique courte, compréhensible et transmissible.
