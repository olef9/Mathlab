# ✂️ Création géométrique

> *« Les mathématiques permettent de créer des objets aussi précis que créatifs. »*

---

# Principe

Les élèves réalisent une création répondant à une mission précise.

Cette réalisation s'appuie sur des propriétés géométriques.

L'objectif n'est pas de reproduire un modèle.

Les élèves doivent imaginer une solution originale tout en respectant des contraintes mathématiques.

Les outils utilisés peuvent varier :

- pliage ;
- découpage ;
- constructions géométriques ;
- assemblages ;
- pavages ;
- rosaces ;
- frises ;
- figures triangulées ;
- créations personnelles.

---

# Pourquoi utiliser ce format ?

La création géométrique montre que la géométrie n'est pas seulement un ensemble de techniques.

Elle permet :

- d'imaginer ;
- d'expérimenter ;
- d'inventer ;
- de produire une réalisation unique.

Les contraintes mathématiques deviennent un moteur de créativité.

---

# Objectifs

Les élèves apprennent à :

- respecter un cahier des charges ;
- mobiliser des connaissances géométriques ;
- faire des choix ;
- améliorer une production ;
- expliquer leurs décisions.

# Les caractéristiques d'une bonne mission

Une mission :

✔ comporte plusieurs contraintes géométriques ;

✔ laisse une liberté de création ;

✔ produit une réalisation valorisable ;

✔ permet plusieurs solutions.

---

# Exemples de missions

🎯 Concevoir une rosace originale.

🎯 Inventer un animal uniquement à partir de triangles.

🎯 Réaliser une frise destinée à décorer le Math'Lab.

🎯 Créer un pavage inédit.

🎯 Concevoir une carte de vœux géométrique.

🎯 Fabriquer une décoration utilisant uniquement certaines figures.

🎯 Réaliser un origami répondant à un défi mathématique.

---

# Déroulement type

## 1. Mission

Présentation du défi.

Analyse des contraintes.

---

## 2. Recherche

Croquis.

Essais.

Choix de plusieurs idées.

---

## 3. Réalisation

Construction progressive.

Les élèves améliorent leur création au fur et à mesure.

---

## 4. Finalisation

Mise en valeur.

Coloriage si nécessaire.

Présentation soignée.

---

## 5. Exposition

Les élèves expliquent :

- leurs choix ;
- les propriétés utilisées ;
- les difficultés rencontrées.

---

# Différenciation

## Pour aider

- proposer un point de départ ;
- limiter le nombre de contraintes ;
- fournir quelques modèles.

---

## Pour aller plus loin

- ajouter des contraintes supplémentaires ;
- créer une série cohérente ;
- réaliser une œuvre collaborative ;
- rédiger un guide de construction.

# Erreurs fréquentes

Les élèves peuvent :

- privilégier uniquement l'esthétique ;

- oublier les contraintes géométriques ;

- vouloir réaliser un projet trop ambitieux.

Le rappel essentiel :

> Une belle création est d'abord une création mathématiquement cohérente.

---

# Conseils de mise en œuvre

Commencer par une mission simple.

Laisser plusieurs solutions possibles.

Prévoir un temps de présentation.

Conserver les productions pour enrichir progressivement la galerie du Math'Lab.

# Place dans le Math'Lab

La création géométrique montre que les mathématiques permettent d'imaginer, de concevoir et de réaliser des productions originales.

Chaque création devient une rencontre entre la rigueur mathématique et l'imagination.

> **Créer, c'est donner une forme visible à une idée mathématique.**
