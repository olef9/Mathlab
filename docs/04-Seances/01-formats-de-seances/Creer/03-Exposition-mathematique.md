# 🖼️ Exposition mathématique

> *« Une réalisation prend encore plus de valeur lorsqu'elle est expliquée et partagée. »*

---

# Principe

Les élèves conçoivent une exposition destinée à présenter des productions mathématiques.

L'objectif n'est pas uniquement de montrer un résultat.

Les élèves doivent également expliquer :

- leur démarche ;
- les notions mobilisées ;
- les choix réalisés.

Une exposition raconte une histoire mathématique.

---

# Pourquoi utiliser ce format ?

Présenter une production oblige à prendre du recul.

Les élèves apprennent à :

- sélectionner les informations essentielles ;
- organiser un parcours clair ;
- mettre en valeur une réalisation ;
- adapter leurs explications à un public.

---

# Objectifs

Les élèves apprennent à :

- valoriser une production ;
- communiquer des idées mathématiques ;
- concevoir une présentation lisible ;
- justifier leurs choix ;
- travailler en équipe.

- créativité ;

---

# Les caractéristiques d'une bonne exposition

Une exposition :

✔ répond à un thème précis ;

✔ est lisible ;

✔ présente des réalisations variées ;

✔ explique les mathématiques utilisées ;

✔ invite le visiteur à observer et à comprendre.

---

# Exemples de missions

🎯 Préparer une exposition sur les rosaces réalisées par la classe.

🎯 Mettre en valeur les plus beaux pavages.

🎯 Créer une galerie d'animaux triangulés.

🎯 Présenter les projets Scratch réalisés pendant l'année.

🎯 Organiser l'exposition de fin d'année du Math'Lab.

# Déroulement type

## 1. Mission

Identifier le public et le thème.

---

## 2. Sélection

Choisir les productions.

Repérer les informations importantes.

---

## 3. Mise en scène

Organiser les espaces.

Préparer les affiches.

Rédiger les légendes.

---

## 4. Présentation

Tester le parcours.

Vérifier la compréhension.

---

## 5. Visite

Présenter l'exposition.

Répondre aux questions.

Recueillir les retours.

---

# Différenciation

## Pour aider

- proposer un modèle d'affiche ;
- fournir une trame de légende ;
- limiter le nombre de productions.

---

## Pour aller plus loin

- organiser une exposition interactive ;
- créer un parcours avec énigmes ;
- accueillir une autre classe ;
- préparer une visite guidée.

# Erreurs fréquentes

Les élèves peuvent :

- vouloir tout montrer ;
- oublier d'expliquer les mathématiques ;
- privilégier uniquement l'aspect esthétique.

Le rappel essentiel :

> Une exposition réussie donne envie de regarder… mais surtout de comprendre.

# Place dans le Math'Lab

L'exposition mathématique valorise le travail réalisé tout au long de l'année.

Elle montre que les mathématiques peuvent être partagées, expliquées et admirées.

> Les mathématiques prennent une nouvelle dimension lorsqu'elles sont exposées au regard des autres.
