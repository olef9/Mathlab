# 🕵️ Enquêtes mathématiques

> *« Un mathématicien est parfois un enquêteur : il observe, questionne et rassemble des preuves. »*

---

# Principe

Les élèves doivent résoudre une situation en utilisant différentes informations mises à leur disposition.

Ils deviennent enquêteurs.

Ils doivent :

- analyser les données ;
- sélectionner les informations utiles ;
- éliminer les fausses pistes ;
- construire une argumentation ;
- présenter leur conclusion.

L'enquête peut prendre différentes formes :

- retrouver un personnage ;
- identifier une figure ;
- résoudre un mystère ;
- vérifier une affirmation ;
- retrouver une information cachée.

---

# Pourquoi utiliser ce format ?

Dans la vie réelle comme en sciences, une conclusion solide repose sur des informations vérifiées.

Les élèves apprennent progressivement que :

- toutes les informations ne sont pas forcément utiles ;
- certaines informations peuvent être trompeuses ;
- une affirmation doit être justifiée.

Ce format développe une véritable culture du raisonnement.

---

# Objectifs

Les élèves apprennent à :

- analyser une situation complexe ;
- sélectionner les informations pertinentes ;
- organiser une démarche ;
- construire une justification ;
- communiquer une conclusion argumentée.

# Les caractéristiques d'une bonne enquête

Une bonne enquête :

✔ possède une question claire ;

✔ contient des informations variées ;

✔ oblige à faire des choix ;

✔ permet plusieurs stratégies ;

✔ demande une justification finale.

# Déroulement type

## 1. Lancement de l'enquête (5 min)

Présentation du mystère.

Les élèves identifient :

- la question à résoudre ;
- les informations disponibles ;
- les contraintes.

---

## 2. Exploration individuelle (5 min)

Chaque élève observe les documents.

Il note :

- ses premières remarques ;
- ses hypothèses ;
- les informations importantes.

---

## 3. Enquête en équipe (25 min)

Les équipes organisent leur investigation.

Elles peuvent :

- classer les indices ;
- éliminer des possibilités ;
- construire des tableaux ;
- vérifier leurs hypothèses.

L'enseignant accompagne par des questions.

---

## 4. Rapport d'enquête (10 min)

Chaque équipe présente :

- son hypothèse ;
- les indices utilisés ;
- son raisonnement.

La conclusion doit être justifiée.

---

## 5. Retour réflexif (5 min)

Les élèves analysent leur démarche :

- Quel indice a été décisif ?
- Quelle information était inutile ?
- Quelle stratégie a permis d'avancer ?

---

# Différenciation

## Pour aider

- réduire le nombre d'indices ;
- donner les informations progressivement ;
- proposer un tableau d'organisation ;
- accompagner le classement des données.

---

## Pour aller plus loin

- ajouter des indices ambigus ;
- demander plusieurs hypothèses ;
- faire créer une nouvelle enquête ;
- demander une preuve complète.

# Variantes possibles

## Enquête progressive

Les indices sont révélés petit à petit.

---

## Enquête libre

Toutes les informations sont disponibles dès le départ.

---

## Enquête numérique

Recherche et traitement d'informations avec ordinateur.

---

## Enquête grandeur nature

Utilisation de la salle, du collège ou de l'environnement proche.

---

# Erreurs fréquentes

Les élèves peuvent :

- utiliser tous les indices sans réfléchir ;
- se précipiter sur une hypothèse ;
- oublier de justifier leur conclusion.

Le rappel essentiel :

> Un bon enquêteur ne cherche pas seulement une réponse, il cherche des preuves.

---

# Conseils de mise en œuvre

Ce format fonctionne particulièrement bien lorsque l'histoire donne du sens aux mathématiques.

Les élèves peuvent être mis dans une posture de :

- détective ;
- architecte ;
- scientifique ;
- journaliste ;
- explorateur.

L'habillage doit rester au service du raisonnement.
