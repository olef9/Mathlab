# 🔎 Chercher
## Lire en premier

---

# Pourquoi cette famille ?

Chercher est au cœur de l'activité mathématique.

Pourtant, les élèves pensent souvent qu'en mathématiques il existe une seule méthode et une seule bonne réponse.

Le Math'Lab propose une autre approche.

Dans cette famille d'activités, l'objectif n'est pas de trouver rapidement la solution. Il est d'apprendre à chercher.

Les élèves découvrent progressivement que :

- chercher demande du temps ;
- plusieurs stratégies peuvent être efficaces ;
- l'erreur fait partie de la démarche ;
- expliquer son raisonnement est aussi important que donner une réponse.

---

# Une posture de chercheur

Les activités de cette famille invitent les élèves à adopter une véritable démarche de recherche.

Ils apprennent à :

- observer la situation ;
- comprendre le problème posé ;
- formuler des hypothèses ;
- tester plusieurs idées ;
- revenir en arrière si nécessaire ;
- comparer différentes stratégies ;
- justifier leurs choix.

L'objectif est de développer leur autonomie face à une situation nouvelle.

---

# Une progression pensée pour toute l'année

Les formats proposés permettent d'aborder la recherche sous différents angles.

| Format | Ce qu'il développe principalement |
|--------|-----------------------------------|
| 🔍 Recherche ouverte | Explorer sans méthode imposée |
| 🤝 Recherche coopérative | Construire une solution en équipe |
| 🧠 Défis de logique | Déduire et raisonner |
| 🕵️ Enquête mathématique | Exploiter des indices et organiser des informations |
| 🎯 Plusieurs solutions | Développer la créativité mathématique |
| ⚖️ Débat mathématique | Argumenter et convaincre |

Chaque format peut être réutilisé plusieurs fois au cours de l'année avec des niveaux de difficulté croissants.

---

# Les principes du Math'Lab

Dans les activités de recherche :

- une erreur est une information utile ;
- une stratégie incomplète mérite d'être discutée ;
- plusieurs démarches peuvent être pertinentes ;
- les échanges entre élèves enrichissent la réflexion.

Le rôle de l'enseignant n'est pas de donner rapidement la solution, mais d'accompagner la recherche.

---

# Le rôle de l'enseignant

Pendant une séance de recherche, l'enseignant privilégie le questionnement.

Quelques exemples :

- « Que sais-tu déjà ? »
- « Qu'as-tu essayé ? »
- « Peux-tu représenter la situation autrement ? »
- « Cette méthode fonctionnera-t-elle toujours ? »
- « Que peux-tu conclure ? »

Ces questions permettent aux élèves de garder la responsabilité de leur recherche.

---

# Donner du temps pour chercher

Une recherche demande du temps.

Il est normal qu'un élève :

- hésite ;
- fasse une fausse piste ;
- recommence ;
- modifie sa stratégie.

Ces étapes font partie de l'apprentissage et ne doivent pas être perçues comme des échecs.

---

# La coopération au service de la recherche

Les échanges entre élèves sont encouragés.

Ils permettent de :

- confronter des idées ;
- expliquer une démarche ;
- repérer une erreur ;
- enrichir une stratégie.

Coopérer ne signifie pas copier, mais construire ensemble une compréhension plus riche.

---

# Valoriser les démarches

Toutes les recherches n'aboutissent pas immédiatement.

Une démarche intéressante peut être valorisée même si elle ne conduit pas directement à la solution attendue.

L'important est que les élèves puissent expliquer :

- ce qu'ils ont essayé ;
- pourquoi ils l'ont fait ;
- ce qu'ils ont appris.

---

# Quelques conseils

✔ Résister à la tentation de donner trop vite une méthode.

✔ Accorder un véritable temps de recherche.

✔ Faire verbaliser les démarches.

✔ Valoriser plusieurs stratégies.

✔ Utiliser les erreurs pour alimenter les échanges.

✔ Terminer chaque séance par une mise en commun.

---

# En résumé

Dans le Math'Lab, chercher est une compétence qui s'apprend.

Les élèves deviennent progressivement capables de :

- explorer une situation nouvelle ;
- organiser leur réflexion ;
- coopérer efficacement ;
- argumenter leurs choix ;
- persévérer face à une difficulté.

> **Chercher, ce n'est pas attendre une idée brillante. C'est construire peu à peu un raisonnement.**
