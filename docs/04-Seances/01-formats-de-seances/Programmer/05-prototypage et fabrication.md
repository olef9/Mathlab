# 🏗️ Prototypage et fabrication

> *« Une idée devient vraiment intéressante lorsqu'elle prend forme. »*

---

# Principe

Les élèves réalisent un prototype répondant à une mission.

Ils découvrent que fabriquer un objet demande bien davantage que lancer une impression.

Ils doivent :

- concevoir ;
- mesurer ;
- vérifier ;
- corriger ;
- améliorer.

La fabrication devient une étape de validation.

---

# Pourquoi utiliser ce format ?

Fabriquer un objet donne une valeur particulière au travail réalisé.

Les élèves découvrent que :

- la précision est indispensable ;
- une erreur de conception peut empêcher la fabrication ;
- améliorer un prototype fait partie du travail.

Ils comprennent que les mathématiques sont présentes dans les objets qui les entourent.

---

# Objectifs

Les élèves apprennent à :

- préparer un prototype ;
- vérifier les dimensions ;
- anticiper les contraintes de fabrication ;
- tester un objet ;
- améliorer une conception.

# Les caractéristiques d'une bonne mission

Une mission :

✔ répond à un besoin réel ;

✔ produit un objet utile ;

✔ peut être améliorée ;

✔ valorise la précision.

---

# Exemples de missions

🎯 Fabriquer un porte-clés d'équipe.

🎯 Concevoir un support pour smartphone.

🎯 Réaliser un pion de jeu.

🎯 Créer un trophée du Math'Lab.

🎯 Concevoir un outil pour une autre activité.

🎯 Fabriquer un matériel manipulable de mathématiques.

# Erreurs fréquentes

Les élèves peuvent :

- oublier de vérifier les dimensions ;

- négliger les assemblages ;

- imprimer sans tester la conception ;

- croire que le premier prototype est définitif.

Le rappel essentiel :

> Un prototype est fait pour être amélioré.

---

# Conseils de mise en œuvre

Lorsque cela est possible :

- faire manipuler le prototype ;

- encourager les retours des autres équipes ;

- conserver les différentes versions pour montrer les progrès.
