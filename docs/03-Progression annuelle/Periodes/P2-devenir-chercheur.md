# 🔎 Période 2 — Devenir chercheur

> *Utiliser les outils du Math'Lab pour développer une véritable démarche de recherche.*

---

# Objectifs de la période

Après la découverte du fonctionnement du laboratoire, les élèves développent leur posture de chercheur.

Ils apprennent à :

- explorer plusieurs pistes ;
- construire une stratégie ;
- justifier leurs choix ;
- expliquer leur raisonnement.

---

# La grande évolution de l'élève

L'élève passe progressivement de :

> "Je participe à une activité"

à :

> "Je cherche une solution et j'explique ma démarche."

---

# Les compétences Math'Lab développées

## 🔎 Explorer

Les élèves apprennent à :

- tester ;
- expérimenter ;
- comparer ;
- modifier une stratégie.

---

## 🧠 Raisonner

Ils développent leur capacité à :

- observer ;
- émettre des hypothèses ;
- argumenter ;
- prouver.

---

## 🔄 Apprendre de ses erreurs

Les élèves comprennent que :

- une tentative apporte des informations ;
- une erreur peut aider à progresser ;
- la recherche fait partie du processus.

---

## 🎤 Présenter

Les élèves développent leur capacité à :

- expliquer une démarche ;
- présenter un résultat ;
- écouter et analyser d'autres solutions.

---

# Les outils du Math'Lab continuent à se développer

Les élèves continuent d'utiliser les différents espaces du laboratoire.

---

## 📐 Géométrie

Exemples :

- constructions plus complexes ;
- recherche de propriétés ;
- défis géométriques.

---

## 🧩 Défis

Les défis deviennent plus ouverts.

Exemples :

- trouver plusieurs solutions ;
- optimiser une construction ;
- résoudre une énigme collective.

---

## 💻 Programmation

Premières activités de création :

- modifier un programme ;
- comprendre un algorithme ;
- créer une petite animation.

---

## 🌀 Créations mathématiques

Les élèves peuvent réaliser :

- origamis mathématiques ;
- pavages ;
- productions géométriques.

---

# Les premières réalisations

Les élèves commencent à produire des créations personnelles.

Exemples :

- une énigme créée par l'équipe ;
- un jeu mathématique simple ;
- une construction expliquée ;
- une animation numérique.

Ces productions préparent les projets plus ambitieux.

---

# Les mathématiques travaillées

Les activités permettent de développer :

- calcul ;
- résolution de problèmes ;
- géométrie ;
- organisation de données ;
- algorithmique.

---

# L'évolution des équipes

Les équipes deviennent plus autonomes.

Les élèves apprennent à :

- répartir les tâches ;
- organiser une recherche ;
- garder des traces ;
- défendre leurs choix.

---

# Les réussites valorisées

Les élèves peuvent obtenir de nouveaux badges :

- Persévérant ;
- Chercheur ;
- Analyste ;
- Communicateur.

---

# Bilan de période

À la fin de la période, l'élève doit pouvoir dire :

> "Je sais chercher, essayer plusieurs solutions et expliquer mon raisonnement."
