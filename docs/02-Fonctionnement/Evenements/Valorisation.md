# 🏅 La valorisation au Math'Lab

> *Ce qui est partagé prend de la valeur. Le Math'Lab rend visibles les apprentissages et les réussites des élèves.*

---

# Pourquoi valoriser ?

La valorisation permet aux élèves de :

- prendre confiance ;
- être fiers de leurs réalisations ;
- apprendre à expliquer leur travail ;
- reconnaître les réussites des autres.

Elle montre que les mathématiques sont aussi une aventure collective.

---

# Les formes de valorisation

Le Math'Lab utilise plusieurs moyens pour mettre en valeur les apprentissages.

---

# 🏅 Les badges

Les badges reconnaissent des compétences particulières.

Ils valorisent :

- les savoir-faire ;
- les qualités personnelles ;
- l'engagement dans le laboratoire.

➡️ [Découvrir les badges](../Badges/index.md)

---

# ⭐ Les XP

Les XP rendent visibles les progrès réalisés.

Ils permettent de suivre :

- les défis accomplis ;
- les projets réalisés ;
- les engagements dans l'équipe.

➡️ [Découvrir les XP](../XP/index.md)

---

# 🖼️ Les affichages du laboratoire

Le Math'Lab garde des traces visibles.

Exemples :

- affiches d'équipes ;
- productions d'élèves ;
- photos de réalisations ;
- défis réussis ;
- parcours des projets.

Ces traces donnent une identité au laboratoire.

---

# 🎤 Les présentations

Les élèves présentent régulièrement leurs travaux.

Ils peuvent expliquer :

- leur démarche ;
- leurs recherches ;
- leurs choix ;
- leurs difficultés.

La capacité à communiquer fait partie des apprentissages.

---

# 🏛️ Les expositions

Certains projets peuvent être présentés lors d'événements particuliers :

- portes ouvertes ;
- exposition de fin d'année ;
- présentation aux autres classes ;
- rencontres avec les familles.

---

# 📖 Le carnet du Math'Lab

Les élèves conservent une trace de leur parcours.

Il peut contenir :

- les défis réalisés ;
- les projets ;
- les badges obtenus ;
- les réussites personnelles.

---

# La valorisation des erreurs

Dans le Math'Lab, les erreurs ont aussi une valeur.

Elles permettent de :

- comprendre ;
- progresser ;
- améliorer une idée.

Une recherche intéressante peut être valorisée même si elle n'aboutit pas immédiatement.

---

# Conseils pour l'enseignant

La valorisation doit rester :

- régulière ;
- équitable ;
- encourageante.

Il est important de mettre en avant des réussites variées :

- créativité ;
- persévérance ;
- coopération ;
- rigueur ;
- autonomie.

---

# À retenir

La valorisation transforme les productions des élèves en véritables réalisations.

Elle donne du sens au travail accompli et renforce l'esprit du Math'Lab.
