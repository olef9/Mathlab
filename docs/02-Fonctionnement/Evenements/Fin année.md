# 🎓 La fin d'année au Math'Lab

> *Une année de recherches, de défis et de créations mérite d'être célébrée.*

---

# Les objectifs de la fin d'année

La fin d'année permet de :

- faire le bilan des apprentissages ;
- valoriser les réalisations ;
- célébrer les progrès ;
- garder une trace de l'aventure Math'Lab.

---

# Le bilan des équipes

Chaque équipe réalise un retour sur son parcours.

Elle peut présenter :

- ses projets ;
- ses défis préférés ;
- ses réussites ;
- ses difficultés ;
- les compétences développées.

---

# 🖼️ L'exposition Math'Lab

Les réalisations des élèves peuvent être présentées lors d'un moment spécial.

Exemples :

- constructions géométriques ;
- créations 3D ;
- jeux mathématiques ;
- programmes Scratch ;
- parcours MathCity ;
- affiches.

L'exposition permet de montrer que les mathématiques peuvent être créatives et concrètes.

---

# 🏅 La cérémonie des réussites

La fin d'année peut être l'occasion de remettre :

- les badges obtenus ;
- les distinctions particulières ;
- les récompenses collectives.

La cérémonie met en avant les parcours de chacun.

---

# 📜 Le diplôme Math'Lab

Chaque élève peut recevoir une trace de son parcours.

Le diplôme peut mentionner :

- son niveau atteint ;
- ses badges ;
- ses projets ;
- ses réussites particulières.

---

# 📸 La mémoire du Math'Lab

Les traces de l'année peuvent être conservées :

- photos des projets ;
- productions d'élèves ;
- carnets d'équipe ;
- affiches ;
- bilans.

Ces éléments permettent de construire la mémoire du laboratoire.

---

# Le dernier défi

Une dernière mission peut être proposée aux élèves.

Exemples :

- défi collectif de clôture ;
- grande énigme ;
- construction commune ;
- projet surprise.

L'objectif est de terminer l'année sur une réussite collective.

---

# Conseils pour l'enseignant

La fin d'année doit être un moment positif.

Il ne s'agit pas seulement de récompenser les meilleurs résultats, mais de célébrer :

- les progrès ;
- les efforts ;
- les découvertes ;
- les réussites de chacun.

---

# À retenir

La fin d'année donne une conclusion au parcours Math'Lab.

Elle transforme une année de travail en une véritable expérience collective.
