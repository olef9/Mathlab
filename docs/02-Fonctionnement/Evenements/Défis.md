# 🧩 Les défis du Math'Lab

> *Chercher, expérimenter, essayer, se tromper et recommencer : les défis sont au cœur du Math'Lab.*

---

# Pourquoi des défis ?

Les défis permettent aux élèves de mobiliser leurs connaissances dans des situations variées.

Ils développent :

- la recherche ;
- le raisonnement ;
- la créativité ;
- la coopération ;
- l'autonomie.

---

# Les types de défis

Le Math'Lab propose plusieurs familles de défis.

---

# 🧮 Défis mathématiques

Les élèves cherchent des solutions à des problèmes variés.

Exemples :

- énigmes ;
- problèmes ouverts ;
- défis de calcul ;
- recherches de stratégies.

---

# 📐 Défis de construction

Les élèves manipulent et construisent.

Exemples :

- figures géométriques ;
- solides ;
- maquettes ;
- puzzles.

---

# 💻 Défis numériques

Les élèves utilisent les outils numériques.

Exemples :

- programmation Scratch ;
- modélisation 3D ;
- créations numériques ;
- parcours interactifs.

---

# 🤝 Défis coopératifs

Les élèves doivent réussir ensemble.

Exemples :

- construction collective ;
- mission chronométrée ;
- résolution en équipe ;
- défi avec contraintes.

---

# Organisation d'un défi

Chaque défi suit généralement quatre étapes.

## 1. Découverte

Les élèves prennent connaissance de la mission.

---

## 2. Recherche

Les équipes cherchent, testent et expérimentent.

L'erreur est considérée comme une étape normale de la recherche.

---

## 3. Présentation

Les équipes expliquent :

- leur démarche ;
- leurs choix ;
- leur solution.

---

## 4. Bilan

La classe analyse :

- ce qui a fonctionné ;
- les difficultés rencontrées ;
- les stratégies utilisées.

---

# Les récompenses

Les défis peuvent permettre de gagner :

- des XP ;
- des badges ;
- une reconnaissance particulière.

La réussite n'est pas uniquement liée au résultat final.

La démarche et la coopération sont également valorisées.

---

# Exemples de défis

Quelques exemples :

- Construire la tour la plus haute avec un nombre limité de pièces.
- Créer un programme Scratch répondant à une mission.
- Résoudre une énigme collective.
- Concevoir un objet mathématique imprimable en 3D.
- Créer une étape d'un parcours MathCity.

---

# Conseils pour l'enseignant

Varier les difficultés et les formats.

Certains défis peuvent durer :

- 10 minutes ;
- une séance complète ;
- plusieurs semaines dans le cadre d'un projet.

---

# À retenir

Les défis sont des moments privilégiés où les élèves deviennent acteurs de leurs apprentissages.

Ils cherchent, coopèrent et construisent ensemble.
