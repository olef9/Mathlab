# ⚙️ Fonctionnement du Math'Lab

> *Le Math'Lab est un espace où les élèves apprennent les mathématiques en cherchant, en expérimentant et en collaborant.*

---

# Les grands principes

Le fonctionnement du Math'Lab repose sur plusieurs idées fortes :

- apprendre par la recherche ;
- manipuler et expérimenter ;
- travailler en équipe ;
- développer l'autonomie ;
- valoriser les progrès ;
- donner du sens aux apprentissages.

---

# Les piliers du Math'Lab

## 👥 Les équipes

Les élèves travaillent régulièrement en équipes stables.

Chaque équipe possède :

- une identité propre ;
- des rôles répartis ;
- un kit de matériel ;
- un carnet d'équipe.

➡️ [Découvrir les équipes](Equipes/index.md)

---

## 🏅 Les badges

Les badges permettent de valoriser les compétences et les réussites.

Ils sont organisés en plusieurs niveaux :

- Bronze ;
- Argent ;
- Or ;
- Légende ;
- Secrets.

➡️ [Découvrir les badges](Badges/index.md)

---

## ⭐ Les XP

Les XP permettent de suivre la progression dans l'aventure Math'Lab.

Ils récompensent :

- les efforts ;
- les défis réalisés ;
- les progrès ;
- l'engagement.

➡️ [Découvrir les XP](XP/index.md)

---

## 🚀 Les niveaux

Les niveaux représentent les grandes étapes du parcours Math'Lab.

Ils permettent à chaque élève de visualiser sa progression personnelle.

➡️ [Découvrir les niveaux](Niveaux/index.md)

---

## 🏆 Les événements

Tout au long de l'année, le Math'Lab propose des moments particuliers :

- grands défis ;
- projets collectifs ;
- expositions ;
- présentations ;
- cérémonies.

➡️ [Découvrir les événements](Evenements/index.md)

---

# Le rôle de l'enseignant

Le professeur organise le cadre, accompagne les recherches et valorise les progrès.

Il veille à créer un environnement où :

- l'erreur devient une source d'apprentissage ;
- chacun peut participer ;
- les réussites sont reconnues.

---

# Le parcours d'un élève

Au cours de l'année, un élève :

1. découvre le fonctionnement du Math'Lab ;
2. apprend à coopérer ;
3. relève des défis ;
4. développe ses compétences ;
5. construit son propre parcours.

---

# À retenir

Le Math'Lab n'est pas seulement une façon différente de faire des mathématiques.

C'est un environnement où les élèves deviennent progressivement :

- chercheurs ;
- créateurs ;
- coopérateurs ;
- acteurs de leurs apprentissages.
