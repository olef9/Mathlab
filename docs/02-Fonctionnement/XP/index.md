# ⭐ Les XP

> *Les XP permettent de suivre la progression des élèves dans l'aventure Math'Lab.*

---

# Pourquoi des XP ?

Les XP rendent visibles les efforts et les progrès réalisés.

Ils permettent de valoriser :

- les réussites ;
- l'investissement ;
- la coopération ;
- la créativité ;
- la persévérance.

Les XP ne remplacent pas les évaluations scolaires.

Ils représentent le parcours de l'élève dans le Math'Lab.

---

# Comment gagner des XP ?

Les élèves peuvent gagner des XP grâce à :

- la réussite d'un défi ;
- l'obtention d'un badge ;
- une bonne coopération ;
- une réalisation créative ;
- une participation active ;
- un effort remarquable.

---

# Les XP individuels et collectifs

Le Math'Lab utilise deux types d'XP.

## ⭐ XP individuels

Ils récompensent le parcours personnel de chaque élève.

Exemples :

- obtention d'un badge ;
- réussite d'une mission ;
- progression personnelle.

---

## 👥 XP d'équipe

Ils récompensent la dynamique du groupe.

Exemples :

- coopération efficace ;
- matériel bien géré ;
- défi collectif réussi.

---

# Les XP et les badges

Les XP permettent de mesurer la progression.

Les badges reconnaissent une compétence particulière.

Les deux systèmes sont complémentaires :

- les XP montrent le parcours ;
- les badges montrent les réussites.

---

# Les XP et les niveaux

L'accumulation des XP permet de franchir différents niveaux.

Chaque niveau représente une étape dans l'aventure Math'Lab.

---

# Les XP ne sont pas une compétition

Chaque élève progresse selon son propre parcours.

L'objectif n'est pas d'avoir plus d'XP que les autres, mais de progresser régulièrement.

---

# À retenir

Les XP sont un outil de motivation et de valorisation.

Ils permettent de rendre visibles les progrès réalisés tout au long de l'année.
