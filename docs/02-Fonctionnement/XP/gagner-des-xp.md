# ⭐ Gagner des XP

> *Chaque action positive dans le Math'Lab peut permettre de gagner de l'expérience.*

---

# Comment gagner des XP ?

Les XP sont obtenus grâce aux apprentissages, aux défis et aux comportements qui font vivre le Math'Lab.

Ils récompensent :

- les progrès ;
- l'engagement ;
- la coopération ;
- la créativité ;
- la persévérance.

---

# Barème des XP

| Action | XP gagnés |
|---|---:|
| Participation active à une activité | +5 XP |
| Défi réussi | +10 XP |
| Défi important ou projet terminé | +20 XP |
| Badge Bronze obtenu | +20 XP |
| Badge Argent obtenu | +40 XP |
| Badge Or obtenu | +80 XP |
| Badge Légende obtenu | +150 XP |
| Contribution exceptionnelle au Math'Lab | Bonus du professeur |

---

# Les bonus du professeur

L'enseignant peut attribuer exceptionnellement des XP supplémentaires pour valoriser :

- une idée originale ;
- une aide remarquable ;
- une progression importante ;
- une attitude exemplaire.

Ces bonus doivent rester rares afin de conserver leur valeur.

---

# Les XP d'équipe

Certaines réussites sont récompensées collectivement.

Exemples :

- défi réalisé en équipe ;
- excellente coopération ;
- matériel parfaitement géré ;
- projet collectif réussi.

Les XP d'équipe ne remplacent pas les XP individuels.

---

# Les erreurs ne font pas perdre d'XP

Dans le Math'Lab, l'erreur fait partie de l'apprentissage.

Un élève ne perd jamais d'XP parce qu'il :

- se trompe ;
- cherche une solution ;
- rencontre une difficulté.

La progression est toujours encouragée.

---

# Suivre ses XP

Chaque élève peut suivre sa progression grâce à :

- son carnet Math'Lab ;
- son espace numérique ;
- le tableau de progression de la classe.

---

# À retenir

Les XP récompensent les efforts et les progrès.

Ils permettent de voir son évolution tout au long de l'année.
