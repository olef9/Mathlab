# 🎨 L'identité des équipes

> *Une équipe n'est pas seulement un groupe d'élèves. C'est une identité commune qui favorise l'engagement et le sentiment d'appartenance.*

---

# Pourquoi créer une identité ?

Donner une identité à chaque équipe permet de renforcer :

- le sentiment d'appartenance ;
- la motivation ;
- la coopération ;
- la fierté des réalisations communes.

L'identité accompagne les élèves tout au long de l'année.

---

# Les éléments de l'identité

Chaque équipe choisit :

## 🏷️ Un nom

Le nom doit évoquer les mathématiques, la logique ou les sciences.

### Quelques exemples

- Les Polyèdres
- Les Fractales
- Les Tangrams
- Les Fibonacci
- Les Hexagones
- Les Spirales
- Les Pythagoriciens
- Les Algorithmes

---

## 🎨 Une couleur

Chaque équipe choisit une couleur qui sera utilisée sur :

- la caisse de matériel ;
- les badges ;
- les affichages ;
- les fiches d'équipe.

---

## 🛡️ Un logo

Le logo est créé par les élèves.

Il pourra être dessiné à la main ou réalisé avec un outil numérique.

---

## 💬 Une devise

La devise représente l'esprit de l'équipe.

Quelques exemples :

- « Chercher, comprendre, réussir. »
- « Ensemble, chaque défi devient possible. »
- « Une idée vaut mieux que dix réponses toutes faites. »

---

# Présentation de l'équipe

En début d'année, chaque équipe présente :

- son nom ;
- son logo ;
- sa devise ;
- les raisons de ses choix.

Cette présentation constitue le premier défi collectif.

---

# Conseils pour l'enseignant

Laisser les élèves choisir librement leur identité tout en veillant au respect des valeurs du Math'Lab.

Cette activité permet d'installer rapidement un climat de coopération.

---

# À retenir

L'identité de l'équipe crée un sentiment d'appartenance qui favorise l'engagement et la coopération pendant toute l'année.
