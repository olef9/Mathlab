# 📖 Le carnet d'équipe

> *Le carnet d'équipe retrace l'histoire, les réussites et les progrès de chaque équipe tout au long de l'année.*

---

# Pourquoi un carnet d'équipe ?

Le carnet d'équipe permet de conserver une trace des activités réalisées et des progrès accomplis.

Il valorise le travail collectif et permet aux élèves de mesurer le chemin parcouru.

Il constitue également un support d'échange entre les élèves et l'enseignant.

---

# Les informations de l'équipe

La première page présente :

- le nom de l'équipe ;
- le logo ;
- la couleur ;
- la devise ;
- les membres de l'équipe.

Cette page accompagne l'équipe pendant toute l'année.

---

# Les missions réalisées

Après chaque défi ou projet, l'équipe peut compléter une fiche indiquant :

- le nom de la mission ;
- la date ;
- les objectifs ;
- le résultat obtenu ;
- les compétences mobilisées.

Le carnet devient progressivement le journal de bord de l'équipe.

---

# Les badges obtenus

Le carnet comporte une page permettant de suivre :

- les badges collectifs ;
- les récompenses spéciales ;
- les trophées éventuels.

Les élèves visualisent ainsi leurs réussites.

---

# Les XP d'équipe

Une page est consacrée au suivi des XP.

Elle indique :

- les XP gagnés ;
- leur origine ;
- le total atteint.

Les élèves peuvent ainsi suivre leur progression au fil des semaines.

---

# Les moments marquants

L'équipe peut conserver une trace :

- d'une photographie ;
- d'une réalisation ;
- d'une construction ;
- d'un projet ;
- d'un défi particulièrement réussi.

Ces souvenirs donnent une dimension plus personnelle au carnet.

---

# Le bilan de fin d'année

En fin d'année, les élèves prennent un moment pour réfléchir :

- Qu'avons-nous appris ?
- De quoi sommes-nous les plus fiers ?
- Quels défis avons-nous préférés ?
- Comment avons-nous progressé ?

Ce bilan permet de clôturer l'année en valorisant le parcours accompli.

---

# Conseils pour l'enseignant

Le carnet n'a pas besoin d'être rempli après chaque séance.

Quelques minutes à la fin d'un projet ou d'un défi important suffisent pour conserver une mémoire fidèle de l'année.

---

# À retenir

Le carnet d'équipe raconte l'histoire du groupe.

Il met en valeur les progrès, les réussites et les expériences vécues ensemble.

Il constitue un souvenir durable du parcours réalisé au Math'Lab.
