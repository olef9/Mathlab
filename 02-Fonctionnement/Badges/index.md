# 🏅 Les badges

> *Les badges valorisent les progrès, les compétences et les attitudes positives des élèves tout au long de l'année.*

---

# Pourquoi des badges ?

Les badges permettent de rendre les réussites visibles.

Ils encouragent les élèves à progresser, à relever de nouveaux défis et à développer des compétences variées.

Chaque badge représente une étape franchie dans le parcours Math'Lab.

---

# Les niveaux de badges

Les badges sont organisés selon quatre niveaux de progression :

🥉 **Bronze** : premières réussites et compétences en développement.

🥈 **Argent** : compétences maîtrisées avec régularité.

🥇 **Or** : très bon niveau de maîtrise et autonomie.

👑 **Légende** : distinction exceptionnelle, obtenue par très peu d'élèves.

---

# Comment obtenir un badge ?

Un badge est attribué lorsque les critères définis sont atteints.

L'obtention d'un badge repose sur :

- les compétences démontrées ;
- les efforts fournis ;
- la régularité ;
- l'engagement dans les activités du Math'Lab.

Chaque badge est validé par le professeur.

---

# Les badges sont-ils obligatoires ?

Non.

Chaque élève progresse à son rythme.

Les badges sont une manière de valoriser les apprentissages, sans remplacer les évaluations habituelles.

---

# Les catégories de badges

Les badges couvrent différents domaines du Math'Lab :

- calcul ;
- géométrie ;
- logique ;
- programmation ;
- coopération ;
- créativité ;
- persévérance ;
- défis.
