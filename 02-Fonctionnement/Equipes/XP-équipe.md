# ⭐ Les XP d'équipe

> *Les XP d'équipe récompensent les attitudes qui permettent à chacun de mieux apprendre ensemble.*

---

# Pourquoi des XP d'équipe ?

Les XP d'équipe mettent en valeur les comportements collectifs.

Ils encouragent :

- la coopération ;
- l'entraide ;
- l'organisation ;
- la persévérance ;
- le respect du matériel ;
- l'engagement.

Les XP ne récompensent pas uniquement le résultat obtenu, mais aussi la manière de travailler.

---

# Comment gagner des XP ?

Une équipe peut gagner des XP lorsqu'elle :

- coopère efficacement ;
- écoute tous ses membres ;
- partage les responsabilités ;
- aide une autre équipe ;
- range parfaitement son matériel ;
- termine un défi collectif ;
- présente un travail de qualité ;
- fait preuve de créativité ;
- persévère face à une difficulté.

---

# Exemples de récompenses

| Situation | XP |
|-----------|---:|
| Kit parfaitement rangé | +5 XP |
| Toute l'équipe participe | +5 XP |
| Présentation claire et argumentée | +10 XP |
| Aide spontanée à une autre équipe | +10 XP |
| Défi collectif réussi | +20 XP |
| Esprit d'équipe remarquable | Bonus du professeur |

---

# Les bonus du professeur

L'enseignant peut attribuer des XP supplémentaires pour valoriser des comportements particulièrement positifs.

Quelques exemples :

- une excellente coopération ;
- une attitude exemplaire ;
- une idée originale ;
- une grande persévérance.

Ces bonus restent exceptionnels afin de conserver leur valeur.

---

# Ce que les XP ne récompensent pas

Les XP ne servent pas à comparer les élèves.

Ils ne récompensent pas :

- la rapidité ;
- la compétition ;
- les moqueries ;
- les comportements individuels au détriment du groupe.

L'objectif est de faire progresser toute l'équipe.

---

# Conseils pour l'enseignant

Attribuer les XP avec régularité et expliquer clairement pourquoi ils sont accordés.

Les élèves comprennent ainsi que ce sont leurs attitudes qui sont valorisées autant que leurs réussites.

---

# À retenir

Les XP d'équipe encouragent les comportements qui favorisent un climat de travail positif.

Ils rappellent que réussir ensemble est aussi important que réussir individuellement.
