# 🏗️ Les projets du Math'Lab

> *Dans le Math'Lab, les élèves ne font pas seulement des exercices : ils imaginent, construisent et réalisent des projets.*

---

# Pourquoi des projets ?

Les projets permettent aux élèves de mobiliser leurs connaissances dans des situations concrètes.

Ils développent :

- l'autonomie ;
- la créativité ;
- la coopération ;
- la gestion de projet ;
- la capacité à présenter une réalisation.

---

# La démarche de projet

Un projet Math'Lab suit généralement plusieurs étapes.

---

## 💡 1. Imaginer

Les élèves réfléchissent à une idée.

Ils cherchent :

- un objectif ;
- une solution ;
- les moyens nécessaires.

---

## ✏️ 2. Concevoir

Les équipes préparent leur réalisation.

Elles peuvent :

- réaliser des plans ;
- faire des essais ;
- répartir les rôles ;
- organiser le travail.

---

## 🛠️ 3. Construire

Les élèves passent à la réalisation.

Ils peuvent :

- fabriquer ;
- programmer ;
- modéliser ;
- expérimenter.

---

## 🎤 4. Présenter

Chaque projet est présenté.

Les élèves expliquent :

- leur démarche ;
- leurs choix ;
- les difficultés rencontrées ;
- les améliorations possibles.

---

# Les grands projets du Math'Lab

## 🌍 MathCity

Créer des parcours mathématiques dans l'environnement réel.

Les élèves imaginent :

- des énigmes ;
- des questions ;
- des étapes de recherche.

---

## 💻 Programmation

Créer des productions numériques.

Exemples :

- jeux Scratch ;
- animations ;
- programmes interactifs.

---

## 🖨️ Création 3D

Imaginer et fabriquer des objets.

Exemples :

- objets mathématiques ;
- puzzles ;
- constructions ;
- supports pédagogiques.

---

## 📐 Géométrie et arts

Créer des réalisations mêlant mathématiques et créativité.

Exemples :

- origami ;
- pavages ;
- rosaces ;
- constructions géométriques.

---

## 🎲 Jeux mathématiques

Concevoir des jeux pour apprendre.

Exemples :

- jeux de cartes ;
- plateaux ;
- énigmes ;
- défis collaboratifs.

---

# Valorisation des projets

Les réalisations peuvent être présentées :

- aux autres classes ;
- aux familles ;
- lors d'une exposition ;
- dans le laboratoire ;
- sur un espace numérique.

---

# Les projets et les XP

Les projets peuvent permettre de gagner :

- des XP individuels ;
- des XP d'équipe ;
- des badges spécifiques.

La qualité du résultat compte, mais la démarche est également valorisée.

---

# Conseils pour l'enseignant

Un projet n'a pas besoin d'être long pour être intéressant.

L'important est que les élèves :

- cherchent ;
- construisent ;
- expliquent ;
- progressent.

---

# À retenir

Les projets transforment les élèves en créateurs.

Ils donnent du sens aux apprentissages et laissent une trace durable du travail réalisé dans le Math'Lab.
