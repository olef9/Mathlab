# 🚀 Le lancement du Math'Lab

> *La première mission des élèves : découvrir leur nouveau laboratoire de mathématiques.*

---

# Objectifs du lancement

La séance de lancement permet aux élèves de :

- découvrir l'esprit du Math'Lab ;
- comprendre son fonctionnement ;
- créer leur identité d'équipe ;
- réaliser leurs premières expériences.

---

# Durée conseillée

⏱️ 1 à 2 séances selon le temps disponible.

---

# Étape 1 — Bienvenue au Math'Lab

Le professeur présente :

- le concept du laboratoire ;
- les objectifs de l'année ;
- les grands principes :
  - chercher ;
  - expérimenter ;
  - coopérer ;
  - créer.

L'objectif est de donner envie aux élèves d'entrer dans l'aventure.

---

# Étape 2 — Découverte des équipes

Les élèves découvrent leur équipe.

Chaque équipe choisit :

- un nom ;
- un logo ;
- une couleur ;
- une devise.

Elle crée sa première identité visuelle.

---

# Étape 3 — Installation du fonctionnement

Les élèves découvrent :

- les rôles dans l'équipe ;
- le kit de matériel ;
- le carnet d'équipe ;
- les règles de coopération.

---

# Étape 4 — Première mission

Les élèves réalisent un premier défi court.

Exemples :

- construction collective ;
- énigme mathématique ;
- défi logique ;
- activité de manipulation.

L'objectif n'est pas la difficulté mathématique, mais d'observer :

- la coopération ;
- l'organisation ;
- la communication.

---

# Étape 5 — Premiers XP

Les premières réussites peuvent être valorisées.

Exemples :

- équipe bien organisée ;
- bonne coopération ;
- première mission réussie.

Les élèves découvrent ainsi le système de progression.

---

# Conseils pour l'enseignant

Ne pas chercher à tout installer immédiatement.

Les règles du Math'Lab se construisent progressivement.

Les premières semaines servent à apprendre :

- à travailler ensemble ;
- à chercher ;
- à gérer le matériel ;
- à devenir autonome.

---

# À retenir

Le lancement donne le ton de l'année.

Il doit transmettre une idée essentielle :

> *En Math'Lab, on apprend les mathématiques en cherchant, en construisant et en progressant ensemble.*
