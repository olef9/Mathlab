# Repères enseignant – Capsules minute

## Place dans la progression

La séance constitue la première production vidéo destinée au patrimoine Math'Lab.

Elle réinvestit S06 :

```text
but → stratégie → difficulté → conseil
```

et ajoute les contraintes propres à la vidéo :

```text
durée → cadrage → son → support → archivage
```

Le calendrier prévoit des productions vidéo ponctuelles et réparties entre les groupes. Il n'est donc pas nécessaire que chaque équipe explique toutes les activités.

---

# Niveau d'exigence

Pour une première capsule, privilégier :

- une idée mathématique correcte ;
- une structure claire ;
- une voix audible ;
- un support visible ;
- une durée courte.

Ne pas exiger :

- un montage élaboré ;
- des transitions numériques ;
- une musique ;
- plusieurs caméras ;
- une image parfaite ;
- un texte appris par cœur.

Une vidéo techniquement modeste mais mathématiquement claire est réussie.

# Choix des activités

## Activités particulièrement adaptées

### Hextoile

Point fort :

```text
observer → prolonger → utiliser les intersections
```

Risque :

montrer toute la correction.

### Pentominos

Point fort :

```text
chercher → classer → éliminer les doublons
```

Risque :

annoncer immédiatement les douze formes.

### Trioz

Point fort :

```text
repérer des régularités dans une numération inconnue
```

Risque :

présenter toutes les conversions.

### Programme saboté

Point fort :

```text
exécuter → premier écart → correction minimale → nouveau test
```

Très adapté à la vidéo.

### Coffre des quatre verrous

Point fort :

```text
expertises différentes → mise en commun → contraintes d'ordre
```

Risque :

révéler le code final.

### Échecs

Point fort :

```text
capture → reprise → bilan
```

Utiliser une position très simple.

### Tuile transformée

Point fort :

```text
découper → translater → emboîter
```

Très visuel.

### Construction inversée

Point fort :

montrer une consigne ambiguë puis sa version corrigée.

# Organisation avec peu de matériel

## Un seul appareil

Cette configuration reste suffisante pour quatre ou cinq équipes.

Pendant le tournage :

- une équipe filme ;
- une équipe s'installe ;
- les autres répètent ou évaluent leur script.

Le temps total pour cinq équipes est d'environ quinze à dix-huit minutes.

## Aucun appareil disponible

La séance peut rester utile :

- réaliser les capsules en direct devant la classe ;
- enregistrer uniquement l'audio ;
- conserver les scripts ;
- programmer le tournage à un autre moment.

La structure pédagogique ne dépend pas du matériel.

## Plusieurs appareils

Limiter malgré tout le nombre de zones afin de conserver un niveau sonore acceptable.

---

# Cadrage recommandé

Pour éviter les difficultés liées au droit à l'image et pour faciliter la concentration :

- filmer la table vue de dessus ou en légère plongée ;
- montrer les mains ;
- montrer la production ;
- placer la voix hors champ ;
- ne pas afficher les noms.

Ce choix convient particulièrement aux constructions, aux pavages, à l'algorithmique et aux échecs.

---

# Autorisations et diffusion

Distinguer :

## Usage interne

- visionnage dans la classe ;
- conservation dans l'espace pédagogique prévu ;
- utilisation avec les futurs élèves selon les règles de l'établissement.

## Diffusion élargie

- site public ;
- réseau social ;
- exposition accessible hors établissement ;
- partage externe.

Une diffusion élargie nécessite de vérifier les autorisations applicables.

Par défaut, ne pas publier les vidéos.

---

# Validation avant tournage

## Mathématiques

- la démarche est juste ;
- le vocabulaire est précis ;
- le conseil est réellement utile ;
- la capsule ne donne pas une fausse règle générale ;
- le résultat éventuellement montré a été vérifié.

## Communication

- le titre apparaît dans les vingt premières secondes ;
- une seule idée principale est développée ;
- le support est préparé ;
- la conclusion est courte ;
- la durée est réaliste.

## Technique

- l'appareil est stable ;
- le support est dans le champ ;
- la voix est audible ;
- les notifications sont coupées ;
- aucun nom complet n'est visible.

---

# Erreurs fréquentes

## Une introduction trop longue

Couper les salutations et commencer par la mission.

## Lire le texte

Remplacer les phrases complètes par des mots-clés.

## Montrer trop de choses

Une capsule minute n'est pas un cours complet.

## Parler pendant que le support est déplacé

Préparer les objets dans l'ordre avant la prise.

## Masquer la figure avec les mains

Marquer au ruban adhésif la position du support et la zone où poser les mains.

## Employer des mots vagues

Remplacer :

```text
truc, trait, ça, ici, comme ça
```

par le vocabulaire de l'activité.

## Refaire de nombreuses prises

Fixer une limite raisonnable. La recherche d'une vidéo parfaite peut faire perdre l'objectif mathématique.

---

# Retour aux équipes

Utiliser la forme :

```text
clair + utile + amélioration
```

Exemple :

```text
Le but est annoncé rapidement.
La démonstration du déplacement de la tuile est utile.
Pendant la prochaine prise, laissez le gabarit dans le champ lorsque vous expliquez le retournement.
```

Éviter de comparer publiquement la qualité des équipes.

## Conserver avec la vidéo

- le script ;
- le support utilisé ;
- la grille de retour ;
- la date ;
- le nom de l'activité ;
- les conditions de diffusion autorisées.

Ne pas intégrer le nom complet des élèves dans le nom du fichier.

# Après la séance

L'enseignant peut classer les capsules en trois catégories :

## À conserver immédiatement

Mathématiquement juste et compréhensible.

## À conserver après une reprise courte

Un mot faux, une partie inaudible ou une durée trop longue.

## À ne pas archiver

Erreur mathématique importante, problème de droit à l'image ou fichier inutilisable.

Il n'est pas nécessaire de refaire toutes les capsules le jour même.

# Prolongements

## Capsule ultra-courte

Réduire une capsule à 45 secondes.

## Version sans parole

Expliquer seulement avec :

- des cartes ;
- des symboles ;
- des gestes ;
- trois phrases écrites.

## Capsule critique

Montrer une erreur fréquente puis demander au spectateur de la repérer.

## Comparaison S06–S14

Comparer :

- présentation orale ;
- capsule filmée ;
- avantages ;
- contraintes ;
- améliorations.
