# Repères enseignant – Construction inversée

## Finalité

La séance développe la compétence **Communiquer**.

Le programme n'est pas évalué uniquement par sa conformité au vocabulaire scolaire. Il doit produire une figure suffisamment proche de la carte secrète lorsqu'il est exécuté par un destinataire qui ne connaît pas cette carte.

Le test constitue donc une étape essentielle.

---

# Description des cartes

## Carte A – La cible carrée

Support initial :

```text
carré ABCD
```

Figure secrète :

1. diagonales `[AC]` et `[BD]` ;
2. point `O`, intersection des diagonales ;
3. milieux `E`, `F`, `G`, `H` des quatre côtés ;
4. quadrilatère `EFGH` ;
5. cercle de centre `O` passant par `E`.

### Programme possible

```text
1. Trace les segments [AC] et [BD].
2. Nomme O leur point d'intersection.
3. Place E, F, G et H, milieux respectifs de [AB], [BC], [CD] et [DA].
4. Trace les segments [EF], [FG], [GH] et [HE].
5. Trace le cercle de centre O passant par E.
```

---

## Carte B – Le moulin

Support initial :

```text
carré ABCD
```

Figure secrète :

1. diagonales ;
2. point central `O` ;
3. milieux `E`, `F`, `G`, `H` ;
4. segments `[AF]`, `[BG]`, `[CH]`, `[DE]`.

### Programme possible

```text
1. Trace les diagonales [AC] et [BD].
2. Nomme O leur point d'intersection.
3. Place E, F, G et H, milieux respectifs de [AB], [BC], [CD] et [DA].
4. Trace [AF], [BG], [CH] et [DE].
```

Le point `O` n'est pas indispensable pour la suite, mais il structure la lecture de la figure. Un groupe peut remarquer que l'étape 2 est inutile : c'est une bonne discussion sur l'économie du programme.

---

## Carte C – L'œil triangulaire

Support initial :

```text
triangle ABC
```

Figure secrète :

1. milieux `D`, `E`, `F` de `[AB]`, `[BC]`, `[CA]` ;
2. triangle `DEF` ;
3. segments `[AE]`, `[BF]`, `[CD]` ;
4. point `O`, intersection des trois segments ;
5. cercle de centre `O` passant par `D`.

### Programme possible

```text
1. Place D, E et F, milieux respectifs de [AB], [BC] et [CA].
2. Trace [DE], [EF] et [FD].
3. Trace [AE], [BF] et [CD].
4. Nomme O leur point d'intersection.
5. Trace le cercle de centre O passant par D.
```

Dans un triangle non équilatéral, le cercle peut sembler décentré. C'est volontaire : les élèves doivent suivre la définition plutôt que chercher une symétrie visuelle parfaite.

---

## Carte D – La roue

Support initial :

```text
cercle de centre O
diamètres [AC] et [BD]
```

Figure secrète :

1. quadrilatère `ABCD` ;
2. segments `[AB]`, `[BC]`, `[CD]`, `[DA]` ;
3. segments `[AC]` et `[BD]` déjà présents ;
4. milieux `E`, `F`, `G`, `H` des côtés du quadrilatère ;
5. quadrilatère `EFGH`.

### Programme possible

```text
1. Trace [AB], [BC], [CD] et [DA].
2. Place E, F, G et H, milieux respectifs de [AB], [BC], [CD] et [DA].
3. Trace [EF], [FG], [GH] et [HE].
```

# Défis avancés

## Carte E – L'étoile des milieux

Support :

```text
carré ABCD
```

Figure :

- milieux `E`, `F`, `G`, `H` ;
- segments `[AG]`, `[BH]`, `[CE]`, `[DF]` ;
- diagonales ;
- cercle de centre `O`, intersection des diagonales, passant par `E`.

Le programme doit rester inférieur ou égal à dix étapes.

## Carte F – Le double blason

Support :

```text
rectangle ABCD
```

Figure :

- diagonales ;
- centre `O` ;
- milieux des quatre côtés ;
- quadrilatère des milieux ;
- cercle de centre `O` passant par le milieu de `[AB]` ;
- segments reliant chaque sommet au milieu du côté opposé.

# Aides progressives

## Aide 1 – Faire la liste des objets

```text
points à placer
segments à tracer
cercles à tracer
```

## Aide 2 – Construire le graphe des dépendances

Exemple :

```text
diagonales → point O → cercle de centre O
```

## Aide 3 – Donner une banque de verbes

```text
trace – place – nomme – relie
```

## Aide 4 – Numéroter visuellement

L'enseignant peut poser de petites étiquettes `1`, `2`, `3` sur une copie de la carte afin d'aider le groupe à ordonner les étapes.

## Aide 5 – Donner une phrase à corriger

```text
Trace un cercle dans le milieu.
```

L'élève doit préciser :

- le centre ;
- le point par lequel passe le cercle.

# Erreurs fréquentes

## Utiliser un point avant de l'avoir nommé

Exemple :

```text
Trace le cercle de centre O.
```

alors que `O` n'a pas encore été défini.

## Écrire « milieu du carré »

Il faut construire l'intersection des diagonales ou préciser le centre.

## Donner une longueur visuelle

```text
Trace un petit cercle.
```

Le rayon doit être défini par deux points.

## Employer « pareil »

Le destinataire ne sait pas exactement quelle propriété répéter.

## Regrouper trop d'actions

Une longue phrase peut cacher plusieurs étapes et produire une omission.

## Corriger oralement pendant le test

Rappeler que l'erreur observée constitue une donnée utile sur la qualité du programme.

# Prolongements

## Message oral interdit

Faire exécuter un programme seulement à partir d'un enregistrement audio, puis comparer les difficultés avec l'écrit.

## Programme volontairement saboté

Modifier une instruction d'un programme correct et demander à une équipe de localiser l'erreur.
