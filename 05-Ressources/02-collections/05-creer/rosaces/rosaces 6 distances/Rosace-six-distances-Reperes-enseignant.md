# La rosace des six distances – Repères enseignant

## Finalité mathématique

La séance met en évidence le compas comme outil de **report de distance**.

Le cercle de départ a pour centre `O` et pour rayon `OA`.

Lorsque la pointe sèche est placée en `A` et que l'ouverture reste égale à `OA`, le nouvel arc coupe le cercle de départ en deux points. Chacun est :

- à la distance `OA` de `A` ;
- à la distance `OA` de `O`.

Les triangles ainsi obtenus sont équilatéraux.

En répétant le report, on construit les six sommets d'un hexagone régulier inscrit dans le cercle.

---

# Construction de référence

## 1. Premier point

- Placer la pointe sèche en `A`.
- Conserver l'ouverture `OA`.
- Tracer un arc coupant le cercle en `B`.

Alors :

```text
OA = OB = AB
```

Le triangle `OAB` est équilatéral.

## 2. Points suivants

- Placer la pointe sèche en `B` pour obtenir `C`.
- Puis en `C` pour obtenir `D`.
- Puis en `D` pour obtenir `E`.
- Puis en `E` pour obtenir `F`.
- Enfin, le report depuis `F` doit revenir sur `A`.

On obtient six points :

```text
A, B, C, D, E et F
```

et :

```text
AB = BC = CD = DE = EF = FA = OA
```

## 3. Rosace

Avec l'ouverture toujours égale à `OA`, tracer des arcs ou des cercles de centres :

```text
A, B, C, D, E et F
```

Les parties intérieures font apparaître les six pétales.

Selon le choix graphique, on peut :

- tracer les six cercles complets ;
- ou ne conserver que les arcs utiles à la rosace centrale.

## 4. Finitions possibles

- Relier `A-B-C-D-E-F-A` : hexagone régulier.
- Relier `A-C-E-A` et `B-D-F-B` : deux triangles équilatéraux.
- Ajouter une couronne de nouveaux centres obtenus par intersections.
- Colorier les zones selon une rotation d'ordre 6.

---

# Pourquoi six reports ?

Dans un cercle, le côté de l'hexagone régulier inscrit est égal au rayon.

Chaque report correspond à un angle au centre de 60°.

Ainsi :

```text
6 × 60° = 360°
```

Cette justification par les angles n'a pas besoin d'être formalisée pendant la séance si elle arrive avant le chapitre correspondant.

On peut simplement constater que les six reports ferment exactement la construction.

# Progression des aides

## Aide 1 – Utiliser le point donné comme centre

> Place la pointe sèche du compas sur `A`. Que se passe-t-il si tu traces un arc sans changer l'ouverture ?

## Aide 2 – Nommer l'intersection

Faire repérer un premier point `B`.

Demander :

> Quelles distances sont égales dans le triangle `OAB` ?

## Aide 3 – Reproduire le mécanisme

> Le point `B` peut-il maintenant jouer le même rôle que `A` ?

## Aide 4 – Chaîne partielle

Construire `B` et `C`, puis laisser l'élève poursuivre.

## Aide 5 – Six points fournis

Pour un élève très en difficulté, fournir directement les six points afin qu'il réussisse la rosace.

# Erreurs fréquentes

## Modifier l'ouverture du compas

La rosace ne se referme plus.

Réponse possible :

> Quelle distance devait rester identique pendant toute la construction ?

## Placer les points à l'œil

Les pétales deviennent irréguliers.

Demander :

> Comment ce point peut-il être obtenu comme intersection de deux tracés ?

## Utiliser le crayon du compas comme pointe sèche

Faire verbaliser le rôle des deux branches :

- pointe sèche : centre ;
- mine : trace.

## Piquer approximativement

Un petit écart se propage autour du cercle.

Faire agrandir légèrement le point et placer soigneusement la pointe sèche.

## Tracer des cercles complets trop épais

Les zones deviennent illisibles.

Faire tracer légèrement les constructions, puis repasser uniquement le motif choisi.

## Commencer le coloriage avant la validation

Le coloriage peut masquer une construction fausse.

---

# Validation de la construction

La rosace de base est validée lorsque :

- six points ont été construits ;
- le dernier report revient sur `A` ;
- l'ouverture n'a pas changé ;
- les six pétales sont visibles ;
- les intersections sont précises ;
- aucune position n'a été choisie au hasard.

Une légère imprécision instrumentale est acceptable si la démarche est comprise.

# Points à observer

| Indicateur | Observation possible |
|---|---|
| Compas | L'ouverture reste-t-elle constante ? |
| Centre | La pointe sèche est-elle placée sur le bon point ? |
| Intersection | Les nouveaux points sont-ils construits ? |
| Régularité | L'élève répète-t-il correctement le mécanisme ? |
| Fermeture | Le sixième report revient-il sur `A` ? |
| Précision | Les traits sont-ils fins et les points nets ? |
| Création | La finition respecte-t-elle la structure de base ? |
| Communication | L'élève peut-il expliquer le premier report ? |

---

# Bilan conseillé

Faire montrer un compas fermé à l'ouverture `OA`.

Question centrale :

> Qu'est-ce qui est resté invariant pendant toute la construction ?

Réponse attendue :

```text
La distance entre les deux branches du compas.
```

Faire distinguer :

- le centre du cercle ou de l'arc ;
- le rayon ;
- les points d'intersection ;
- la figure créative finale.

Synthèse :

> Le compas ne sert pas seulement à tracer un cercle.  
> Il permet de transporter une distance sans la mesurer.
