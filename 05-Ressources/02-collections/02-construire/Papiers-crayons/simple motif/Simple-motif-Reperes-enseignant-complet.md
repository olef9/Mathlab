# Simple motif – Repères enseignant

## Source

Activité **Simple motif**, collection *Papiers Crayons*, IREM Paris-Nord.

La version éco indique de placer les points d'intersection entre le cercle `c1` et les demi-droites :

```text
d5, d15, d25, d33, d43 et d54
```

Elle doit être utilisée avec la feuille-repère « Cercles ».

Conserver l'attribution de l'IREM sur le support.

---

# Finalité

La séance travaille :

- la lecture d'une figure ;
- le placement de points par intersection ;
- l'utilisation de droites, demi-droites et segments ;
- l'organisation d'une construction ;
- la reconnaissance d'une structure répétée six fois ;
- la vérification autonome.

Le motif est plus complexe qu'il n'y paraît, car les élèves doivent comprendre comment les six bandes s'enchaînent autour de l'hexagone central.

---

# Lecture du modèle

Faire repérer trois couches.

## Couche 1 – L'espace central

Un hexagone blanc constitue le vide central.

## Couche 2 – La couronne

Six bandes quadrilatérales entourent cet hexagone.

## Couche 3 – Le contour extérieur

Un second hexagone forme la limite extérieure.

Les six séparations obliques donnent l'impression que les bandes se chevauchent ou tournent.

---

# Construction de référence

L'ordre exact dépend de la feuille-repère utilisée.

Une organisation efficace consiste à :

1. placer les six points demandés ;
2. construire d'abord l'hexagone intérieur ;
3. prolonger les directions utiles pour obtenir le contour extérieur ;
4. tracer une séparation oblique dans une première bande ;
5. reproduire le même principe autour du centre ;
6. vérifier la fermeture complète ;
7. repasser les traits définitifs ;
8. colorier alternativement.

La correction ne doit pas être donnée sous forme d'un programme complet au départ.

---

# Aides progressives

## Aide 1 – Décomposer le motif

Faire entourer ou surligner :

- l'hexagone intérieur ;
- l'hexagone extérieur ;
- une bande seulement.

## Aide 2 – Commencer par l'intérieur

Donner le premier côté de l'hexagone intérieur.

Demander :

> Quel même principe peux-tu répéter autour du centre ?

## Aide 3 – Faire apparaître une bande

Tracer une seule séparation oblique.

Demander ensuite aux élèves de reproduire le mécanisme sur la bande suivante.

## Aide 4 – Numéroter les positions

Numéroter les six zones de 1 à 6 dans le sens des aiguilles d'une montre.

L'élève traite une zone après l'autre.

## Aide 5 – Support partiellement construit

Fournir :

- les six points ;
- l'hexagone intérieur ;
- une bande complète.

L'élève poursuit les cinq autres.

---

# Erreurs fréquentes

## Points de départ imprécis

Toute la figure se décale.

Faire recommencer le placement avant d'ajouter les tracés.

## Confusion entre segment et demi-droite

Une ligne s'arrête trop tôt et l'intersection utile n'apparaît pas.

## Contour intérieur non fermé

Les élèves construisent les bandes une par une sans vérifier la structure centrale.

## Bandes de formes différentes

Faire comparer les six zones par rotation visuelle.

## Colorier trop tôt

Le coloriage masque les erreurs de construction.

## Effacer les traits utiles

Certains traits de construction constituent aussi les limites des bandes.

---

# Validation

La construction est considérée comme réussie si :

- les six points de départ sont corrects ;
- le contour intérieur est fermé ;
- le contour extérieur est fermé ;
- six bandes sont identifiables ;
- les séparations sont cohérentes ;
- la figure possède une organisation régulière ;
- le coloriage renforce la lecture sans masquer les tracés.

---

# Gestion des rythmes

## Élèves en difficulté

Objectif minimal :

- placer correctement les six points ;
- construire l'hexagone intérieur ;
- terminer au moins trois bandes avec aide.

Une version partiellement construite peut être donnée.

## Élèves dans le rythme

Réaliser le motif complet puis un coloriage alterné.

## Élèves rapides

Choisir une activité :

- écrire les premières étapes d'un programme de construction ;
- inverser le sens visuel du motif ;
- créer une nouvelle gamme de couleurs ;
- essayer de reproduire le motif sans modèle ;
- expliquer une bande à une autre équipe sans montrer la solution.

# Seconde construction pour les élèves rapides – Soissons

## Pourquoi choisir Soissons ?

Soissons appartient à la même série que Hextoile et Simple motif : constructions avec la règle seule utilisant droites et demi-droites.

Dans la progression numérique de l'IREM Paris-Nord, Soissons est placé immédiatement après Simple motif. Il constitue donc un prolongement cohérent et plus dense.

Le support officiel comporte :

- le modèle terminé ;
- un grand octogone de départ.

La version économique utilise la feuille-repère « Cercles » et demande de placer les intersections du cercle `c1` avec les demi-droites :

```text
d3, d11, d19, d27, d31, d39, d48 et d56
```

## Objectif pendant S09

Il n'est pas nécessaire que Soissons soit terminé.

Pour un groupe rapide, l'objectif raisonnable est de :

1. analyser le modèle ;
2. repérer le centre ;
3. tracer les huit directions ;
4. construire deux motifs voisins ;
5. identifier la répétition alternée ;
6. poursuivre seul si le temps le permet.

## Lecture du modèle

Soissons est organisé autour d'un centre commun.

On observe :

- huit rayons ou directions principales ;
- huit zones grises qui convergent vers le centre ;
- quatre carrés dont les côtés sont horizontaux ou verticaux ;
- quatre carrés tournés d'un huitième de tour, apparaissant comme des losanges ;
- un contour noir formé de huit secteurs ;
- une alternance carré / losange répétée quatre fois.

## Aides progressives

### Aide 1 – Repérer le centre

Demander :

> Où se rejoignent toutes les grandes directions de la figure ?

### Aide 2 – Tracer les directions

Faire relier le centre aux huit sommets ou points remarquables de l'octogone.

### Aide 3 – Isoler deux motifs voisins

Masquer temporairement le reste du modèle et ne conserver visuellement :

- un carré droit ;
- le losange voisin ;
- les deux zones grises correspondantes.

### Aide 4 – Construire un premier carré

Aider l'élève à repérer les quatre droites qui délimitent un carré blanc.

### Aide 5 – Exploiter la répétition

Demander :

> Après un carré droit, quelle forme vient toujours ?  
> Quel angle de rotation semble séparer deux motifs voisins ?

Il n'est pas nécessaire de formaliser l'angle de 45° à ce stade.

## Critères de réussite

Le défi est réussi si l'élève :

- ne place aucun point au hasard ;
- utilise le centre et les directions principales ;
- construit au moins deux formes voisines correctement ;
- comprend l'alternance carré / losange ;
- peut expliquer comment poursuivre autour du centre.

## Gestion matérielle

Créer une pochette :

```text
S09 – Défis à poursuivre
```

Les constructions Soissons non terminées y sont conservées.

Elles peuvent être reprises :

- en fin d'une autre séance ;
- lors d'une absence d'activité numérique ;
- pendant un atelier autonome ;
- comme défi facultatif à la maison, sans obligation.


# Prolongements précis

## Prolongement 1 – Programme de construction

Rédiger un programme suffisamment précis pour une équipe qui possède la même feuille-repère.

Critères :

- ordre logique ;
- vocabulaire correct ;
- points et lignes clairement désignés ;
- absence de consigne ambiguë.

## Prolongement 2 – Motif inversé

Modifier les séparations pour donner l'impression que les bandes tournent dans l'autre sens.

L'élève doit expliquer quelle modification produit cet effet.

## Prolongement 3 – Couronne étendue

Prolonger certaines directions pour créer une seconde couronne autour du motif.

La nouvelle figure doit conserver une organisation en six parties.

## Prolongement 4 – Explication vidéo

Préparer une capsule de deux minutes :

1. présenter la structure générale ;
2. expliquer le rôle des six points ;
3. montrer une étape utile ;
4. laisser la suite à chercher.

Ne pas montrer une correction complète.

---

# Bilan conseillé

Question centrale :

> Qu'est-ce qui se répète six fois dans cette figure ?

Faire émerger :

- une même bande ;
- une même séparation ;
- une même organisation autour du centre.

Comparer avec Hextoile :

- Hextoile fait surtout apparaître de nouveaux points par prolongement ;
- Simple motif demande davantage de lire une structure fermée et répétitive.

Synthèse :

> Repérer une partie qui se répète permet de comprendre et de construire une figure complexe.
