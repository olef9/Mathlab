# Robomorpion – Intégration future

## Placement proposé

L’activité sera intégrée principalement à :

```text
S22 – Si… alors…
Univers : Programmer
```

Elle correspond directement à l’introduction de décisions conditionnelles.

## Règles du robot

```text
SI la case contient un rond
ALORS tourner à gauche

SI la case est vide
ALORS avancer tout droit

SI la case contient une croix
ALORS tourner à droite
```

## Exploitation de la page 1

- comprendre les trois règles ;
- prévoir un trajet ;
- tracer un trajet complet ;
- retrouver un trajet à partir de la sortie ;
- distinguer position et orientation ;
- identifier la première décision incorrecte.

## Exploitation de la page 2

- utiliser les sorties comme code de substitution ;
- décoder un message secret ;
- construire une grille reliant des entrées et sorties imposées ;
- créer un défi pour une autre équipe.
